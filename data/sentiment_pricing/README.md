# 情绪定价响应实验

后续已完成[信号分工与转向速度两步实验](roles/README.md)。两步均未通过全部保护条件，默认影子仍沿用本文件的原组合；新候选在报告中单独展示。

本轮遵照用户要求冻结基本面及宽可比池，只检验情绪反馈进入价格的效果。

- [回放报告](review.md)：同样本基准、两项单独响应及预先指定的组合候选，包含近期和更早区段、降温子集及低估反例。
- `protocol.json`：首次候选回放前冻结的规则、参数、39份输入哈希；存在时不覆盖。
- `replay.json`：65条输入中63条有首日结果，全部保留评分/不可用原因；2条缺结果单列。48条有共同预测，最近10只中9条可用。
- `audit.json`、`validation.json`：冻结输入、时点、价格归属、37个回归脚本及15项新规则验证。

原情绪基准为提交2a501dc的quality_sentiment_v1_structural配合已复核的宽池基本面，不是行业分类修正前的最早模型。最近10只结果已知，更早区段也属于研究重建，均不是独立样本外验证。

预测兑现反馈：最近3个实际上市日组的首日均价相对冻结基准预测的对数误差。承接变化：D2/D3分别相对更早相同期限的常态，不把普遍存在的上市后折价重复扣除。各项先按上市日组平均，再乘n/(n+3)；总调幅限制约-20%至+25%，上下对称。缺数据时该项不调价并标记不可用，不额外细分行业。

正式价格和原影子中枢不变。主流程另存`response_shadow`，报告展示候选区间及两项信号贡献；真实前向存档会一并保留。响应模块异常时仅候选不可用，不阻断原价格。没有改写已有前向快照。


`prepare_sentiment_pricing_protocol.py`只用于首次建立协议。原证据按字节校验；Python/参数文件若仅因Git换行不同，则与冻结提交逐内容核对，不能借此放过参数改变。

当前组合响应降低了近期价格误差和高估，但更早区段的低估有所增加，宇特等案例仍恶化。保留组合为原定研究候选，不根据已知回放结果改选单项赢家；继续影子验证。
