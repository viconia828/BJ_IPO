# 四例基本面复核与影子接入

本目录承接批量可比底稿，先复核安达、宇特、凯达、远大健科。用户要求保留足够参照，因此不以细分标签硬切样本：直接业务参照权重1，相邻产品/工艺0.5，同渠道品牌0.25；不按PE高低或首日涨幅筛选。权重为固定研究设定，尚未获得样本外验证。

- [验收与回放](review.md)：四例结果、相同样本及相同历史覆盖控制、折价/去同行敏感性。
- `review_decisions.json`：有原始页依据的业务判断、股本、盈利修正和周期/预测结论。
- `cases/`：结构化计算输入与逐股可读底稿。旧批量底稿和原始财报值不覆盖。
- `inputs/`：估值时点报价及历史评价输入；实际首日结果不进入基本面决策文件。
- `evidence/`：45页原招股书文本、页码和原PDF SHA256；原PDF仍保存在本机公告目录。
- `raw/`：补采4家同行的Tushare、iFind API/MCP原始结果；MCP的2次传输失败如实保存。
- `index.json`：主流程只读接入入口，读取时校验公司代码、路径和结构化底稿SHA256。
- `audit.json`：原PDF及依赖证据核验、情绪核心算法AST不变证明。
- `validation.json`：35个验证脚本通过，其中新基本面规则18项。

## 计算与时间规则

归母与扣非分别计算2025全年＋2026上半年－2025上半年，除以发行后总股本；同行倍数重新用估值日市值除以相同利润，不能沿用口径不同的现成PE。绿鞋全额仅作摊薄情景。SH/SZ参照沿用0.55市场折价，BJ参照不重复折价；不同市场明细分别保留，NQ缺少可靠流动性/报价口径时仍保留业务身份。

主研究F采用扣非口径，同时显示归母口径。凯达目前扣非PE仅1家有效，主F不可用，归母口径仅作显式参照；不会静默切换分母。四例均未批准周期正常化，预测盈利也未混乘TTM PE。

当前底稿最早可用于2026-10-13采集完成后的影子试算。日期采用排他截点，例如2026-10-14表示10月13日收盘后。历史回放必须显式标记研究重建，不能回填为事前档案或启用正式定价。默认历史流程继续使用当时可得代理；单独消融工具才将本轮研究F用于历史重建。

F情景区间来自同行离散、盈利口径和股本情景，不是概率区间。回放统一使用固定±10%的首日价格区间，不能靠拓宽F区间提高命中率。

## 复现

```powershell
python tools/build_fundamental_cases.py
python tools/evaluate_fundamental_cases.py
python tools/audit_fundamental_cases.py
python tests/validate_fundamental_anchor.py
```

离线构建读取已归档输入。首次采集工具`collect_fundamental_case_supplements.py`使用本机已有认证配置，凭据不入档；`prepare_fundamental_case_evidence.py`需要本机四份招股书，只读提取、不修改原PDF。

35项工程验证通过不代表预测胜出。本轮共同44只旧/新影子线涨幅MAE123.96/127.20个百分点；同历史覆盖旧代理127.53。下一步优先补凯达可验证估值分母和最近8—10只同口径覆盖，继续冻结真实上市前预测；不据这四例调情绪权重。
