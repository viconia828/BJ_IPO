# 估值分类审计与多层标签方案

当前实施版本：v4，2026-10-12。

## 三类信息分别保存

- 法定行业：公告披露的行业名称和代码，保存在 statutory_industry / statutory_industry_code。
- 市场行业：以申万行业名称为参考，保存一级、二级、三级。报表使用一级 / 二级，历史估值样本按照一级与二级共同筛选。
- 产品和产业链：business_tags 保存主营产品，chain_tags 保存业务相关产业链。产业链标签不直接把企业归入客户行业。

示例：

| 公司 | 市场行业 | 主营或产业链 |
|---|---|---|
| 远大健科 920285 | 家用电器 / 家电零部件 | 净水器件、净水产业链、跨境电商 |
| 安达股份 920202 | 汽车 / 汽车零部件 | 汽车铝合金精密压铸件、汽车产业链 |
| 凯达重工 920025 | 机械设备 / 专用设备 | 轧辊、辊环、钢铁产业链 |
| 晨光电机 920011 | 电力设备 / 电机 | 微特电机 |
| 宇特光电 920157 | 通信 / 通信设备 | 光连接产品 |
| 森合高科 920038 | 基础化工 / 化学制品 | 贵金属选矿剂、矿业产业链 |

凯达的法定行业为专用设备制造业。市场分类与钢铁产业链关系同时呈现，避免仅显示“高端装备”，也避免因客户是钢厂就将轧辊企业认作钢铁冶炼企业。

## 决策与证据

1. 用户显式 stock_industry 配置优先。
2. data/industry_classification/market_reference.json 中按证券代码核验的市场行业参考。
3. 未收录公司使用结构化申万行业字段与发行人主营产品规则；出现冲突或多个不同业务组则进入待复核。
4. 行业文本别名映射。
5. 法定行业代码仅作为粗证据。C35 / C38 / C39 等存在跨市场行业歧义时保留候选，不能强行确定二级组。

主营规则只读取发行人业务字段。客户名称、下游应用、同行企业描述不作为企业自身的行业依据。新增公司即使尚无代码级参考，也可以依据“净水器件 / 冰箱滤水器”识别家电零部件，依据“轧辊 / 辊环”识别专用设备并增加钢铁产业链标签。

当前静态参考包含 66 只股票，来自 2026-10-12 iFind 的完整申万行业和主营资料。置信度是规则质量标记，不是统计正确率。provider 参考使用 0.95；主营产品规则使用 0.88；宽泛或冲突证据降权并进入待复核。来源日期和证据随输出保存。已收录公司如果新的发行人主营与参考发生强冲突，同样进入待复核。

旧五大类参数别名仍可读取，但输出转换为市场行业名称。不再把普通汽车零部件、机械、轻工和电子企业统称为高端装备、消费服务等。

## 正式报告与 replay

正式目标股先读取主营描述再分类，报告分别展示市场行业、法定行业及产业链。近期样本表展示完整一级 / 二级，并附产业链标签。

replay 与正式流程使用相同分类器。分类版本及参考文件 SHA256 纳入刷新契约。迁移工具：

python tools/reclassify_replay_industries.py --dry-run
python tools/reclassify_replay_industries.py

工具仅更新分类元数据；对其他字段逐项断言一致，并备份数据集及单股缓存。不会刷新财务、改行情、改估值参数，也不会谎报 PDF 解析版本已经刷新。下次正式同步仍按照实际 PDF 版本决定是否重解析。

方法二按市场一级与二级共同匹配；旧调用只提供二级时保留兼容。无细分类时仍不回退全市场。产业链标签当前用于说明和审计，不将钢铁客户、半导体客户直接转成跨行业可比样本。

## 审计及点时边界

行业审计复用分类器产品规则，不再维护一份独立关键词规则。检查未分类、低置信度、非法分组、静态参考冲突、缓存失配及主营主体冲突。静态参考一致、待复核为零，表示规则与参考一致，不能解释为每家公司已全文人工审定。

2026-10-12 已迁移 65 个历史样本及 65 个单股缓存，58 个行业组名称或归属变化。所有原发行、财务、行情和 PDF 签名均保留，备份及证据在 .tmp/industry_classifier_20261012/。

本次市场行业参考用于当前研究的历史标签纠正，并非各上市日当时可获得的申万分类快照。严格 PIT 研究应使用当时的招股书主营证据和当时分类版本；本次未引入未来收益或财务数值。

## 分类与估值效果分别验收

分类更准确不自动代表现有估值参数更有效。固定策略参数，对同一 65 个样本复算：

| 指标 | 迁移前 | 迁移后 |
|---|---:|---:|
| 可生成估值样本 | 63 | 62 |
| 区间命中率 | 20.97% | 13.11% |
| 涨幅 MAE（百分点） | 117.46 | 124.22 |

行业池变细使样本覆盖和行业情绪统计发生变化。此次未自动修改策略参数；后续参数标定应在新分类数据集上重做时间切片及覆盖率检验，不能沿用旧分类下的命中率作为新版本效果。

旧 validate_local_center_overlay.py 还固化了早期 40 个样本的数值预期。迁移前的当前 65 样本也不符合该快照，需将数据依赖的快照验证与合成场景的行为验证区分维护。
