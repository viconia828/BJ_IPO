# 估值分类审计与多层标签方案

## 背景与问题

`industry_primary / industry_secondary` 同时承担了法定行业记录、主营业务理解和估值样本分组三种职责。证监会行业代码适合说明公司登记在哪个制造门类，却不一定适合决定估值可比组。例如：

- 百瑞吉（920201）和百迈科（920268）法定行业可落在医药制造，但核心产品是三类医疗器械、手术缝线和介入耗材，估值上应进入 `医药生物 / 医疗器械`。
- 维琪科技（920176）和珈凯生物（920165）法定行业可落在化学制品，但主营是化妆品功效原料、活性多肽或生物发酵原料，估值上更接近 `医药生物 / 生物制品`。
- 森合高科（920038）法定行业是化学制品，但产品服务于贵金属选矿，估值上进入 `化工新材 / 金属新材料` 更合理。

现有流程还有两个工程问题：远端记录存在但行业字段为空时，replay 不会用本地招股书补齐；正式报告先映射行业、后追加申购 history 行，后追加的样本不会再分类。这会造成近期样本大量 `未分类`，进而让方法二缺少同行业样本并失效。

## 目标

1. 把事实、估值分组和语义标签分开保存，避免法定行业直接覆盖估值判断。
2. 对已人工复核的代码使用稳定、可审计的代码级映射。
3. replay 和正式报告都在数据合并完成后执行同一套分类。
4. 审计只把高质量主营证据当作冲突信号，降低可比公司章节造成的误报。
5. 分类规则变化进入 replay 刷新契约，旧缓存自动失效一次，之后继续按单样本缓存增量运行。

## 数据模型

保留现有字段作为估值计算的兼容接口：

- `industry_primary`
- `industry_secondary`
- `industry_source`

新增显式字段：

- `statutory_industry`：招股书或数据源披露的法定行业名称。
- `statutory_industry_code`：证监会行业代码。
- `valuation_peer_group`：`一级 / 二级` 格式的估值同类组。
- `business_tags`：产品和商业模式标签，可多值，不直接参与方法二分组。
- `industry_confidence`：0 至 1 的分类置信度。
- `industry_evidence`：做出估值分组所依据的规则或人工复核批次。

其中 `industry_primary / industry_secondary` 是 `valuation_peer_group` 的结构化兼容表示，不再被解释为法定行业。

## 决策优先级

1. `stock_industry` 显式手工配置，置信度 1.00。
2. 已审定的代码级估值映射，置信度 0.98 至 1.00。
3. 行业文本精确或别名映射，置信度 0.80。
4. 证监会行业代码粗映射，置信度 0.60。
5. 无法判断则保持 `未分类`，不把过宽的 C27 医药制造直接塞入一个不存在的二级估值组。

代码级审定映射优先于法定行业文本。法定行业仍原样保存在证据层，便于复核。

## replay 与正式报告流程

### replay

每只样本先解析本地招股书中缺失的 `INDUSTRY / INDUSTRY_CODE`，再统一调用行业映射器。分类版本、字段签名和 PDF 解析器版本一起进入刷新契约：

- 分类规则未变化且单样本缓存命中：直接复用。
- 分类规则变化：旧版本样本重建一次。
- 后续只有新增样本、记录变化或对应 PDF 变化时才重建该样本。

### 正式报告

远端近期新股先与申购 history 合并、再统一分类，确保后追加的行也能命中代码级映射。这个短窗口继续服务申购预测和方法三；方法二在其副本上额外合并本地 replay，补足年初至今历史窗口。replay 合并层先按标的申购/上市日期过滤可见样本，方法二再按自身窗口过滤，不产生未来数据穿越，也不扩大其他模型的样本口径。标的自身在招股书字段补齐后分类。

## 审计规则

审计输出迁移到 `输出/分类审计/`，并同时记录法定行业、估值组、标签、置信度和证据。进入待复核清单的条件为：

- 当前 replay 分类与最新版映射不一致。
- 仍为未分类或置信度低于阈值。
- 二级组不属于五大一级行业的有效分类集合。
- 主营描述疑似把可比公司当成发行人。
- 高质量发行人主营句与当前估值组出现强冲突。

主营抽取优先使用“发行人主营业务情况”等章节，并对包含其他证券代码或已知可比公司名称的候选句降权或拒绝。仅在主语可信时使用关键词推断；下游应用、客户或同行章节里偶然出现“医疗器械”“半导体”不再自动形成强冲突。

## 验收标准

1. 上表代码全部命中约定估值组，920298 不被误报为医疗器械或半导体。
2. 未审定且只有泛化 C27 行业代码的样本保持未分类。
3. replay 中本地招股书行业字段可补齐远端空值。
4. history 后追加的近期样本也具备行业字段。
5. 920201 的方法二能取得 `医疗器械` 历史样本，不再因行业分类为空而缺少估值区间。
6. 现有回归测试全部通过，分类审计可重复运行并给出结构化结果。
