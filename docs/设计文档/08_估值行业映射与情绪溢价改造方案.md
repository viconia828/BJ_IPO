# 估值行业映射与情绪溢价改造方案

## 背景

当前估值框架里，方法二经常因为新股行业字段映射不到二级行业而退回一级行业或全市场，导致汽配/汽零这类近期表现偏弱的细分行业被更强的新股情绪稀释。近期北交所新股还呈现明显的时间序列情绪：前几只新股首日涨幅、次日和第三日能否继续赚钱，会影响下一只新股的估值溢价。

## 目标

- 行业映射尽量使用公告和本地样本里的证监会行业代码，减少退回全市场。
- 方法二只表达“同行业首日涨幅”，不再叠加 PE、流通盘和近期市场情绪。
- 方法二不再退回一级行业或全市场；没有二级行业映射时，方法二不可用。
- 二级行业样本窗口拉长到标的上市当年年初至标的上市日前，使用稳健中位数/去极值，压低单个极端样本影响。
- 方法三单独表达“近期新股情绪溢价”，使用时间衰减，不做稳健统计。
- 方法三输出的是加到基础估值上的溢价，而不是第三个加权目标价。

## 行业映射

行业解析优先级：

1. `stock_industry` 手工指定。
2. 样本/公告字段中的行业文本映射。
3. 已知样本映射表。
4. 公告解析出的 `INDUSTRY_CODE` 证监会行业代码映射。
5. 仍无法识别则返回未分类。

新增 `INDUSTRY_CODE` 后，C36 映射到 `高端装备 / 汽车零部件`，汽配样本应进入同一个二级行业池。

## 方法二

输入：标的发行价、行业映射、历史新股样本。

规则：

- 仅当标的存在有效二级行业时启用。
- 样本必须早于标的上市日。
- 样本范围为标的上市年份内，从 1 月 1 日到标的上市日前。
- 只取同二级行业样本，不回退一级行业或全市场。
- 样本涨幅优先使用 `LD_AVERAGE_CHANGE`，缺失时使用 `LD_CLOSE_CHANGE`。
- 对样本涨幅做稳健处理：样本足够时用 MAD 去极值，然后取中位数；样本不足时直接取中位数。

输出：

- `target_price = issue_price * (1 + 同行业首日涨幅 / 100)`
- 同时记录样本代码、剔除样本、窗口起止、统计口径。

## 方法三

方法三不做稳健统计，只做时间衰减聚合。

样本：

- 使用标的上市日前的近期全市场新股。
- 默认窗口仍由 `recent_days` 控制。
- 每个样本按距离标的上市日的天数做指数衰减，半衰期使用 `sentiment_decay_half_life_days`，缺省回退 `sample_decay_half_life_days`。

两个因子：

1. 近期首日涨幅因子：对 `LD_AVERAGE_CHANGE` / `LD_CLOSE_CHANGE` 做时间衰减加权平均。
2. 次日/第三日赚钱效应因子：优先使用 Tushare 日线收盘价计算第二、第三个交易日相对上市首日收盘价的涨跌幅，再做时间衰减加权平均。

情绪溢价：

- 首日涨幅因子相对基准值的超额部分，乘以 `sentiment_first_day_scale`。
- 次日/第三日赚钱效应因子，乘以 `sentiment_post_listing_scale`。
- 两部分相加后用上下限参数约束，得到 `sentiment_premium_pct`。
- `premium_price = issue_price * sentiment_premium_pct / 100`。

综合估值：

- 先用方法一和方法二按原综合权重得到 `base_target_price`。
- 若方法三可用，则 `target_price = base_target_price + premium_price`。
- 方法三不可用时，综合估值只使用基础估值。

## Tushare 缓存

在 `data/tushare_db/variable_fields/<code>.BJ.json` 中新增字段：

- `tushare_ipo_post_listing_performance`

字段内容包括：

- `listing_date`
- `rows`
- `listing_close`
- `next_trade_date`
- `next_close`
- `third_trade_date`
- `third_close`
- `next_day_change_pct`
- `third_day_change_pct`
- `next_day_from_listing_close_pct`
- `third_day_from_listing_close_pct`
- `post_listing_profit_effect_pct`
- `updated_at`

正式估值和离线调参复用同一个本地缓存；样本已有缓存时不重复拉取。

## 调参

本轮先接入口径和字段，参数保持可调：

- `sentiment_decay_half_life_days`
- `sentiment_first_day_baseline_pct`
- `sentiment_first_day_scale`
- `sentiment_post_listing_scale`
- `sentiment_premium_cap_pct`
- `sentiment_premium_floor_pct`

后续自动调参搜索这些参数时，应以最终估值误差和方向性错误为准，不把方法三作为独立目标价评分。
