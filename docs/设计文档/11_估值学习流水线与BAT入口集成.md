# 估值学习流水线与 BAT 入口集成

> 设计日期：2026-07-11
>
> 状态：已实施

## 一、目标

把本轮形成的本地估值学习逻辑接入现有操作入口，避免用户记忆独立 Python 命令：

1. 估值自动调参结束后，自动刷新方法一锚点可靠性、proxy 动态宽度验收、滚动中枢、regime-break 影子区间和首日盘中指导。
2. `添加新股首日走势.bat` 增加第 3 项“刷新雪球参考”。
3. 用户只需把手工保存的雪球 MHTML/TXT 放进根目录 `xueqiu/`，第 3 项自动导入、验证、学习和生成报告。
4. 全流程禁止从第 3 项自动访问或下载雪球网页。

## 二、入口设计

### 2.1 估值自动调参

`调参.bat -> 估值自动调参` 保留现有搜索与人工确认流程。每次自动调参结束时新增：

- 生成兼容 scan-report 的自动调参影子上下文；
- 记录本轮近期有效样本代码；
- 记录本轮累计最优 overrides、是否接受写回和参数文件路径；
- 自动执行本地估值学习刷新；
- 输出保守候选、滚动中枢、regime-break 和盘中指导报告路径。

参数处理：

- 接受写回：先更新 `策略参数.txt`，再基于新参数刷新影子报告。
- 暂不写回：正式参数不变，但使用本轮累计最优 overrides 生成影子报告。
- 无更优参数：使用当前参数刷新影子报告。
- 影子刷新失败不得回滚已接受的正式参数；应明确报错并返回主调参结果。

自动调参不直接把 proxy、滚动中枢或 regime-break 写入 `策略参数.txt`。这些仍是调参后的扩展评价层。

### 2.2 新增样本 BAT 第 3 项

`添加新股首日走势.bat` 调整为：

1. 刷新新股首日走势。
2. 刷新新上市新股数据。
3. 刷新雪球参考（手工文件）。
4. 退出。

第 3 项执行：

```text
xueqiu/*.mhtml 或 xueqiu/*.txt
  -> 标准语料导入
  -> 可评分区间抽取
  -> 本地样本覆盖审计与作者覆盖表
  -> author-rule score
  -> 作者/模型融合上界
  -> 作者逻辑本地蒸馏
  -> 本地 proxy / regime-break / 盘中指导刷新
```

明确禁止调用：

- `tools/xueqiu_corpus_collect.cjs`
- 任何雪球页面自动抓取、登录或验证码处理逻辑

源文件可长期保留在 `xueqiu/`；导入 ID 应稳定，重复运行不得重复膨胀语料。

## 三、编排脚本

新增两个薄编排层：

- `tools/run_valuation_shadow_pipeline.py`
  - 接收最新 scan/auto 上下文；
  - 运行 `evaluate_local_proxy_strategy.py`、`evaluate_regime_break_fallback.py` 和 `evaluate_intraday_valuation_guidance.py`；
  - 输出本轮统一摘要。
- `tools/refresh_xueqiu_reference.py`
  - 只扫描根目录 `xueqiu/`；
  - 调用手工导入和雪球学习链；
  - 最后复用本地影子估值编排层。

BAT 只负责菜单和调用编排脚本，不复制业务逻辑。

## 四、自动调参上下文

自动调参结束后生成：

- 时间戳归档：`调参/valuation_auto_shadow_context_*.json`
- 当前入口：`调参/valuation_auto_shadow_context_latest.json`

兼容字段：

- `sample_codes`：按自动调参 90 天近期窗口筛选的有实际首日均价样本；
- `top_candidates[0].overrides`：本轮累计最优参数覆盖；
- `auto_tune_status`：`accepted`、`not_accepted` 或 `no_change`；
- `params_file`、`dataset_path`、本轮评分摘要。

这样现有 proxy/distillation 脚本可以通过 `--scan-report` 复用，不再固定依赖 2026-07-10 的旧扫描报告。

## 五、失败与幂等

- `xueqiu/` 不存在时自动创建并提示用户放入文件。
- 文件夹为空时不报系统错误，不触发网络请求。
- 单篇导入失败写入导入报告；关键学习步骤失败时第 3 项返回非零退出码。
- 已导入文章按稳定 ID 覆盖/去重。
- 自动调参影子刷新失败只影响扩展报告，不影响调参结果和已确认的参数写回。
- 所有生成报告继续写入 `outputs/`，正式估值代码与语料原文保持分离。

## 八、自动调参两级重排补充设计

### 8.1 修正目标

第一版集成只在自动调参结束后刷新影子报告，没有影响候选排序。补充实现改为：

1. 第一层继续使用现有近期加权命中率和 MAE 做候选搜索与粗筛。
2. 每轮结束后取核心评分靠前的候选，加上 baseline、阶段起点和核心最优，进入本地学习重排。
3. 重排胜者替换本轮 `best`、`changed_overrides`，并成为下一轮细步长搜索中心。
4. 接受时写回的是两级重排胜者，而不是第一层核心评分胜者。

### 8.2 本地学习重排

每个候选只使用本地可得信息构造三条评价线：

- 保守线：候选模型中枢 + `conservative` 动态宽度 + 本地 `recent_mood` 兜底；当前 90 天窗口平均宽度约 14.7%。
- regime 线：保守线基础上，对已触发情绪断档的兜底使用 `recent_mood_regime_blend50`。
- 滚动线：候选模型与滚动 proxy 中枢做 50% 混合，使用 `layered_v1` 动态宽度；保留较低权重。

作者价格、作者区间、文章正文和作者评分不得进入候选输入。雪球数据只用于此前确定代理字段、宽度层级和评价结构。

默认综合学习分：

```text
45% * 原自动调参核心分
+ 35% * 保守线本地分
+ 15% * regime 线本地分
+  5% * 滚动线本地分
```

本地分由近期加权区间命中率、涨幅 MAE、可用率和平均宽度预算共同组成。平均动态宽度不超过 17% 时不扣分，超过后逐步扣分，避免通过无约束放宽区间提高命中率。

### 8.3 样本与防泄漏

- 重排目标样本与自动调参一致：相对当前基准日向前 90 天、有真实首日均价的样本。
- recent mood、滚动 proxy 和 regime-break 均按上市日期顺序计算，只能读取更早交易日已完成样本。
- 同日上市样本不能互相作为历史。
- proxy 阈值、分位层级和滚动中枢按上市日 walk-forward 计算；早期样本不能读取后来样本的特征分布或标签。
- 实际首日均价只作为回放标签，不作为待预测样本特征。

### 8.4 输出与开关

- 每轮显示核心最优和本地学习重排胜者是否一致。
- 显示综合学习分、保守线/regime 线/滚动线的近期加权命中率、MAE、平均宽度和可用率。
- `--auto-local-rerank-top-n` 控制进入第二层的核心候选数。
- `--no-auto-local-rerank` 可临时恢复旧排序，用于对照或故障隔离。
- 自动调参上下文和自动调参记录同时保存两级评分摘要。

### 8.5 实施与当前回放结果

已新增 `tools/local_learning_auto_rerank.py`，并接入 `tools/tune_params.py` 每轮自动调参结果。

当前 3 轮真实 replay：

- 第 1 轮：核心最优与两级重排最优一致。
- 第 2 轮：核心最优与两级重排最优一致，中心为 `bse_discount_factor=0.625`。
- 第 3 轮：核心评分建议 `bse_discount_factor=0.60` 并新增 `sentiment_decay_half_life_days=12`；两级重排否决该细调，保留第 2 轮中心 `bse_discount_factor=0.625`，不修改半衰期。
- 第 3 轮保守线：21 个近期样本，加权命中率 27.5%，加权 MAE 211.33，平均宽度 14.7%，可用率 100%。
- 第 3 轮 regime 线：加权命中率 27.5%，加权 MAE 212.68，平均宽度 14.7%。
- 第 3 轮滚动线：加权命中率 36.2%，加权 MAE 186.78，平均宽度 19.8%；因其研究属性只占综合分 5%。
- `author_inputs_used=false`，proxy 阈值、分层和滚动中枢均为 walk-forward。

界面会显示“本轮核心评分最优”“本轮两级重排最优”和三条本地评价线。若两者不同，参数建议、下一轮中心、自动调参上下文和接受写回均采用两级重排胜者。

### 8.6 控制台输出

- 编排层成功时只显示步骤开始、完成和 Markdown 报告路径，不转发子脚本 JSON 明细。
- 统一汇总和完整行级结果继续写入 `outputs/*.json`、`outputs/*.md`。
- 子脚本失败时保留 stdout/stderr，确保错误可诊断。
- 自动调参和 BAT 第 3 项采用相同的精简输出规则。

## 九、最新正式估值模型兼容契约与重验证

2026-07-11 晚间，正式模型在两级重排接入后继续完成了三方法职责重构。为避免旧回放结果被误认为仍适用于新模型，自动优化新增模型契约版本 2：

- `composite` 口径必须覆盖方法一的综合权重、北交所折扣、PE/流通盘连续修正和行业 PE 兜底置信度参数；
- `composite` 口径必须覆盖方法二独立权重模式与半衰期，以及方法三独立短期情绪参数；`method2_only` 只覆盖方法二有效参数；
- 自动调参结果和影子上下文记录候选参数全集、必需参数、缺失参数及正式模型结构开关；
- 发现必需参数未进入候选池时直接终止，不能静默使用旧优化口径；
- `method2_only` 回放不再搜索不会生效的方法一参数，避免浪费候选预算。

新增 `tools/revalidate_latest_valuation_auto_optimization.py`，在不写回 `策略参数.txt` 的情况下并行比较：

1. 最新正式参数 baseline；
2. 仅核心自动优化；
3. 核心优化加本地学习二级重排。

报告记录 replay、参数文件及关键模型源码 SHA-256，并分别判断“最新模型兼容性”“核心优化回放效用”和“雪球规则蒸馏二级重排的增量效用”。兼容且成功执行不等于存在增量收益；只有二级重排改变候选选择时，才能继续检验其额外贡献。

2026-07-12 最新 42 样本、五轮完整回放结果：

- 最新模型参数缺口为 0，方法一两个结构开关均已启用，replay 缓存版本为 8；
- 核心自动评分从 -0.264107 改善到 -0.002797，近期加权命中率从 7.30% 提升到 29.96%，加权涨幅 MAE 从 168.54 降至 151.21；
- 原始全样本命中率从 17.95% 提升到 25.64%，但原始涨幅 MAE 从 154.17 上升到 159.76，说明候选更偏近期目标，不能只报命中改善；
- 五轮二级重排均成功执行、保持 walk-forward 且未使用作者价格或文章输入，但五轮选择都与核心最优相同，改变选择 0 次；
- 因此当前结论是“最新模型兼容性通过、核心自动优化在回放目标上有效，但尚未观察到雪球蒸馏二级重排的增量效用”。在正式输出中体现效用前，必须保留这一边界。

## 十、本地滚动中枢正式内化

二级重排没有改变旧参数候选，不代表滚动中枢本身无效。旧重排只用滚动线评价既有三方法参数，没有把滚动中枢作为可部署结构。

- 同日样本不互读实际结果；
- 历史不足 8 只时保持原三方法中枢；
- 正式中枢与最近 20 只历史拟合中枢各占 50%；
- 正式区间继续固定为 ±10%。

写回参数：`local_center_overlay_enabled=True`、`local_center_alpha=0.50`、`local_center_min_history=8`、`local_center_history_window=20`、`local_center_actual_cap_pct=900`、`local_center_slope_cap=25`。

后 12 只留出集相对此前自动候选：命中 4/12→5/12，涨幅 MAE 174.91→129.16；全样本：命中 10/39→11/39，MAE 159.76→122.29，P90 绝对误差 336.41→295.97。通过门槛后参数一次性写入正式 `策略参数.txt`。

## 十一、自动调参参数集 v3 清理与扩展

### 11.1 清理原则

估值自动调参只保留能够改变 `evaluate_replay_targets()` 正式估值输出的参数。走势评分、强弱势阈值及 WSI 盘中权重仍可服务走势判断和盘中观察，但不再混入估值回放候选池；后续如需优化，应使用独立的盘中执行评价标签和调参器。

删除的估值候选组：

- 走势权重；
- 强势走势加成、弱势走势折价；
- 强势走势阈值、弱势走势阈值；
- WSI 权重组合。

旧粗搜索共 21 组、87 个候选，其中上述 31 个候选不会改变估值 replay，现已全部移除。`method2_only` 再按口径收紧为 3 组、14 个候选、4 个有效参数，不再搜索方法一、方法三或本地滚动中枢参数。

### 11.2 新增搜索维度

`composite` 参数池扩展为 20 组、106 个候选、27 个有效参数，新增：

- 方法二稳健过滤：`robust_median_min_samples`、`robust_mad_multiplier` 联合搜索；
- 方法一可比 PE 统计：`comparable_pe_stat` 在 `median` 与 `mean` 间搜索；
- 方法三情绪样本窗：`recent_days`；
- 本地滚动中枢混合：`local_center_alpha`、`local_center_history_window`；
- 本地滚动中枢稳健性：`local_center_min_history`、`local_center_actual_cap_pct`、`local_center_slope_cap`。

固定区间宽度 `price_range_width` 继续不参与自动搜索，避免通过机械放宽区间提高命中率。

### 11.3 正式写回安全门槛

模型契约升级为版本 3。自动评分仍负责在近期样本上排序，但候选要进入最终建议和雪球学习二次排序，还必须相对本轮正式 baseline 同时满足：

1. 全样本原始区间命中率不下降；
2. 全样本涨幅 MAE 不上升；
3. 全样本 P90 绝对误差不上升；
4. 估值可用率不下降。

未通过门槛的候选不会出现在最终 `top_candidates`，雪球学习二次排序也不能将其重新选回；写入入口在执行前再做一次门槛检查。

### 11.4 正式 replay 验证

2026-07-12 使用 replay v8、42 个样本、三轮搜索验证：

- 正式 baseline：原始命中率 28.21%，涨幅 MAE 122.29，P90 绝对误差 295.97；
- 清理扩展后的核心候选：原始命中率 28.21%，涨幅 MAE 121.53，P90 绝对误差 287.99；
- 近期加权命中率保持 26.33%，加权 MAE 138.10→137.22；
- 三轮最终候选均通过正式安全门槛；
- 雪球学习二次排序三轮均与核心候选相同，仍未观察到增量效用。

本次只完成调参系统清理、扩展和重验证，没有写入 `策略参数.txt`。正式报告为 `outputs/latest_valuation_auto_optimization_revalidation_20260712_201359.md`。

## 十二、时间切片稳定性复核

全样本自动搜索与同样本评价只能证明候选在当前 replay 上占优，不能作为样本外写回依据。新增 `tools/revalidate_valuation_time_slices.py`，采用三折锚定式 walk-forward：

| 折次 | 训练前缀 | 冻结参数后的验证段 |
|---|---|---|
| 第 1 折 | 前 20 只，2026-01-16—2026-04-16 | 接下来 7 只，2026-04-20—2026-05-18 |

## 十三、时间切片写回门槛与影子上下文 v2

独立时间切片报告只能形成操作纪律，不能阻止入口误写。自动调参接受流程现改为：

```text
全样本正式安全门槛
  -> 三折时间切片核心/两级路径复核
  -> 参数方向稳定性检查
  -> 全部通过才允许写入策略参数.txt
```

- 如果雪球二级排序已执行，正式写回校验 `two_level` 路径；否则校验 `core` 路径。
- 时间切片执行失败、输出非法、合并指标失败或参数漂移警告均按失败关闭，不能写参数。

影子上下文升级为 `valuation_auto_shadow_context_v2`：

- 每次接受、取消、无修改、正式门槛拒绝或时间切片拒绝都更新 latest 和归档；

- 被拒候选保留在 `candidate` 供审计，但 `top_candidates` 自动回退正式参数，避免影子流水线继续消费失败候选；
- 修复旧 `exact_score` 读取不存在的 `interval_hit` 字段而长期显示 0/0 的问题，改为用实际均价和区间上下限现场计算。

端到端验收：全样本安全门槛通过的 `float_size_threshold=800` 候选，在时间切片门槛失败后被拒绝，`策略参数.txt` 未写入；latest 上下文更新为 `rejected_time_slice`，随后重新生成 proxy、regime-break、盘中指导和统一 shadow 报告。

### 13.1 2026-07-30 临时停用固定样本三折门槛

## 十四、方法一锚点可靠性与动态宽度正式化门槛

### 14.1 方法一锚点可靠性影子实验

`tools/evaluate_method1_anchor_reliability.py` 对方法一直接可比锚新增结构化诊断：可比数量、PE 四分位数、最高/最低倍数、对数 PE 的 MAD 稳健离散倍数、锚点来源，以及方法一/方法二目标价差异。正式参数默认只输出诊断，置信度乘数保持 1.0；影子候选才会按数量、离散度和方法间分歧降权。

候选必须同时满足：全样本命中不下降、MAE/P90 不上升；三折合并命中、MAE、P90 和可用率不恶化；至少两折 MAE 不恶化；任一折不得灾难性退化。业务相似度没有统一结构化字段，本轮不使用文本主观打分。

2026-07-13 的 42 只样本中，38 只使用招股书直接可比锚，10 只只有不超过两家可比，29 只可比 PE 最高/最低达到 3 倍以上。四组数量/离散度/方法分歧候选均未通过验收，因此不修改正式方法一权重。

### 14.2 动态宽度验收框架

`tools/revalidate_dynamic_width_acceptance.py` 固定正式估值中枢，只比较固定 ±10% 与 `layered_v1`、`conservative`、`balanced` 的区间宽度，不混入滚动中枢或情绪兜底。proxy 分层按上市日逐日 walk-forward，同日样本不得互读上市结果。

核心评价量为：

```text
归一化区间损失 = 区间全宽 / 目标价 + 4 × 区间外距离 / 目标价
```

正式化候选必须在全样本和三折合并样本上同时提高命中、降低平均与 P90 区间损失，平均半宽不超过 15%，覆盖/全宽效率不下降，至少两折区间损失不恶化，且任一折不得损失命中只数。

2026-07-13 结果中，`layered_v1` 和 `balanced` 因平均半宽超过 15% 被拒；`conservative` 的全样本平均半宽为 12.7%、三折为 13.1%，但三折 P90 区间损失 5.612 略高于固定宽度的 5.586，同样被拒。因此正式区间继续保持固定 ±10%。

账户池精度不属于本轮工作：官方公告不披露逐金额账户数，当前只能依赖网友信息汇总形成的梯度表；在没有新增可核验数据源前，不通过模型复杂化制造虚假精度。
