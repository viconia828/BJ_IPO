# 情绪组合影子调参控制台

打开根目录 `调参.bat`，选择默认选项 **1：估值自动调参（默认情绪组合影子）**。原综合估值自动调参移至选项5，手动估值和申购入口编号保持不变。

当前接入 `sentiment_response_v1 / combined`。只搜索已有参数 `quality_sentiment_half_life_days` 的4、8、12、16天及当前值，固定基本面、宽可比池、反馈规则和区间宽度。信号分工和转向加速研究候选不参加搜索，旧综合模型的基本面网格与本地重排也不进入这条流程。

## 使用

控制台沿用执行前的统一样本同步。直接运行命令行也会沿用现有数据集刷新规则；只想检查当前本地数据时使用：

```powershell
python tools/tune_params.py --mode sentiment-auto --no-auto-refresh-dataset --sentiment-evaluate-only
```

不指定 `--sentiment-evaluate-only` 时，候选通过检验才显示接受提示。默认不接受，输入 `y` 才写回情绪半衰期。参数文件在回放后变化会拒绝写回；模式必须仍为 `shadow`。下次常规估值读取同一参数，原个股情绪和组合影子随之更新，正式综合价保持原模型。

结果默认保存在 `输出/调参/sentiment_auto_时间戳_随机标识` 下，包含：

- `.md`：整体、训练、后段、近期10只、降温组与四模型共同样本指标，以及逐股价格和未评分原因。
- `.json`：当前正式价、原个股情绪、当前组合、训练选定候选的区间、误差、两路反馈、检验结果、源代码和参数哈希。
- `.inputs.json`：本次使用的完整历史输入、参数与修正记录，供以后精确复核。

接受后追加根目录 `自动调参记录.txt`，标明是情绪影子参数变更。此入口不写入旧综合影子流水线的上下文，不回填历史前向预测。

## 评分与检验

按上市日整组切分，比例沿用 `tuning_train_ratio`（当前策略为0.9），同日新股不会跨训练和检验段。只用训练段的价格MAPE选定一个半衰期；并列保留当前值。然后检验这一个候选，失败就保留当前参数，不在检验段换选其他候选。

写回要求训练至少指定样本数、后段至少5只可评分；与当前组合逐股覆盖一致；训练、后段、全体、最近10只价格MAPE均不恶化；以当前基准固定的降温组高估均值不恶化；最近10只之前的低估均值增幅不超过1个百分点。缺少必要评分组时也不建议写回。

价格误差为 `(预测价格 / 实际首日成交均价 - 1) × 100%`；高估均值将负误差记0，低估均值将正误差记0，二者之和为价格MAPE。涨幅误差以发行价作分母，另列展示。不同模型的可用覆盖不同，比较旧综合与情绪模型要看四模型共同样本。缺少首日均价不使用收盘价替代，缺基本面也不混入旧综合预测后评分。

## 数据边界

读取当前回放数据集与本地已校正行情，复用经过哈希核对的盈利复核案例及已有宽可比输入；同一轮所有候选共享固定输入，每股基本面锚必须完全一致。每个预测仅能读取严格早于其上市日的其他新股结果及D2/D3已知收盘。

复核案例使用显式历史重建模式，不把后来整理的底稿冒充事前快照。近期样本已在研究中使用过，因此这里的后段检验也不宣称为新的独立样本外；实际使用继续依靠后续前向记录。新数据会随样本同步纳入，研究阶段保存的65只冻结回放不被覆盖。
