## 一、项目概述

### 1.1 目标

构建一个 Python 脚本工具，用户输入北交所新股代码后，自动采集数据、计算首日合理定价区间，输出一页纸估值报告。

### 1.2 设计原则

- **自动化优先**：能通过接口/公式获取的数据不手动输入
- **主观输入最小化**：仅在数据源无法覆盖时才需用户补充
- **参数外置**：所有估值系数、权重、阈值写入 `策略参数.txt`，程序中不硬编码
- **双通道容错**：每个数据项至少有主备两条获取路径

### 1.3 输入输出

```
输入：新股代码（如 920012）
      策略参数.txt（可调参数）
      [可选] 公告文件目录下的招股说明书摘要 PDF

输出：一页纸 Markdown 估值报告
      └─ 920012_创达新材_估值_20260414.md
```

### 2.2 备选数据源一：北交所官网公告

#### 用途

当东方财富 API 缺少以下信息时，从北交所官网公告补充：

- **老股转让数量**：API 无此字段，需从上市公告书中获取
- **实际首日流通股数**：= 新股发行量 + 老股转让量
- **可比公司列表**：招股说明书"发行定价"章节
- **详细业务描述**：招股说明书摘要

#### 获取方式

**方式一：自动下载公告 PDF**

北交所公告搜索页通过 AJAX 加载，底层 API 需进一步逆向。备选方案：
- 通过北交所信息披露页面（`www.bse.cn` → 信息披露 → 上市公司公告）
- 按公司名搜索，筛选"上市公告书"、"招股说明书"类型
- 下载 PDF 到 `公告文件\` 目录

**方式二：用户手动放置**

用户从北交所官网手动下载以下文件，放入 `公告文件\` 目录：
- `{代码}_招股说明书摘要.pdf`
- `{代码}_上市公告书.pdf`
- `{代码}_发行公告.pdf`

脚本按命名约定自动识别文件类型。

#### PDF 解析策略

| 文档类型 | 提取目标 | 解析方法 |
|----------|---------|---------|
| 招股说明书摘要 | 公司业务描述、竞争优势 | 提取"发行人基本情况"/"主营业务"章节文本，送 AI 总结 |
| 招股说明书摘要 | 可比公司代码和名称 | 正则匹配"可比公司"段落中的股票代码（6位数字+.SH/.SZ） |
| 上市公告书 | 老股转让数量 | 正则匹配"老股转让"/"存量股份"/"原股东公开发售"等关键词后的数值 |
| 发行公告 | 发行总量、网上发行量确认 | 正则匹配"发行数量"/"公开发行股票"后的数值（与 API 数据交叉验证） |

### 2.3 备选数据源二：Wind（双通道）

#### 通道一：Wind Python API（WindPy）

**已验证状态（2026-04-14）**：

| 股票类型 | 后缀 | wsd close | wsd pe_ttm | wss sec_name | wss ipo_date | 综合评估 |
|----------|------|-----------|------------|-------------|-------------|---------|
| 沪市主板 | .SH | 正常 | 正常 | 正常 | 正常 | **可用** |
| 深市主板/创业板 | .SZ | 正常 | 正常 | 正常 | 正常 | **可用** |
| 北交所（老股） | .NQ | 仅 close | None | 正常 | None | **极有限** |
| 北交所（新股920xxx） | .NQ | None | None | 部分 | None | **不可用** |

**结论**：Wind API 仅用于获取**沪深主板/创业板/科创板可比公司**的估值数据（PE(TTM)、收盘价等），不用于北交所股票本身。

**代码模式**：
```python
from WindPy import w
w.start()

# 获取可比公司当前 PE(TTM) — 可行
data = w.wsd("600519.SH,000858.SZ", "close,pe_ttm", "2026-04-10", "2026-04-10")
# close: [1453.96, ...], pe_ttm: [20.22, ...]

w.stop()
```

#### 通道二：Wind Excel 函数

当 Wind API 返回 None 或连接失败时，自动切换到 Excel 模板方案：

1. 脚本生成一个 `可比公司估值.xlsx`，在指定单元格填入 Wind 函数公式
2. 用户用 Excel 打开（Wind 插件自动计算）
3. 保存后脚本读取计算结果

**Excel 函数示例**：
```
A列：可比公司代码（如 600519.SH）
B列：=W.WSS(A1,"sec_name")           → 公司名称
C列：=W.WSS(A1,"close")              → 最新收盘价
D列：=W.WSS(A1,"pe_ttm")             → PE(TTM)
E列：=W.WSS(A1,"pb_lf")              → PB(LF)
F列：=W.WSS(A1,"mkt_cap_ard")/10000  → 总市值(亿元)
G列：=W.WSS(A1,"eps_ttm")            → EPS(TTM)
```

**触发条件**：
- Wind API 未安装 → 直接走 Excel 通道
- Wind API 连接但某字段返回 None → 该字段回退到 Excel
- 策略参数中 `wind_channel = excel_only` → 强制只用 Excel

### 3.2 数据获取流程

```
输入代码 920012
    │
    ▼
东方财富 API 查询 ─── filter=(SECURITY_CODE="920012")
    │
    ├─ 成功 → 获取上述所有字段
    │         │
    │         ├─ LISTING_DATE 非空 → 已上市，首日表现数据可用
    │         └─ LISTING_DATE 为空 → 未上市，仅有发行信息
    │
    └─ 失败 → 从 公告文件\ 目录读取发行公告 PDF 解析
```

### 3.3 计算项

| 计算项 | 公式 | 说明 |
|--------|------|------|
| 顶格打新金额 | `TOP_APPLY_MARKETCAP`（API 直接提供，单位万元） | 也可通过 `ONLINE_APPLY_UPPER × ISSUE_PRICE / 10000` 计算验证 |
| 发行PE / 行业PE | `AFTER_ISSUE_PE / INDUSTRY_PE_NEW` | 反映发行定价相对行业的折价幅度 |
| 新股 EPS | `ISSUE_PRICE / AFTER_ISSUE_PE` | 后续方法一使用 |
| 首日流通盘 | `TOTAL_ISSUE_NUM + 老股转让量` | 老股转让量从上市公告书获取 |
| 实际流通市值 | `首日流通盘 × 发行价` | 反映首日筹码供给 |

### 3.4 老股转让的获取

老股转让是东方财富 API **唯一缺失的关键字段**。获取策略：

1. **优先**：脚本检查 `公告文件\` 目录是否有 `{代码}_上市公告书.pdf`
   - 如有，用 PyPDF2 / pdfplumber 提取文本
   - 搜索"老股转让"、"存量股份发售"、"原股东公开发售"关键词
   - 提取其后的数值（万股）
2. **备选**：策略参数.txt 中设 `old_shares_transfer = 0`（默认无），用户知道时手动修改
3. **输出提示**：如果未找到老股信息，报告中标注"老股转让信息待确认"

## 四、Part 2：公司概况与可比估值

### 4.1 公司概况（一段话）

#### 生成流程

```
素材获取：
    │
    ├─ 主路径：公告文件\{代码}_招股说明书摘要.pdf
    │   └─ 提取"发行人基本情况"/"主营业务"/"竞争优势"章节
    │
    └─ 备选路径：东方财富 API MAIN_BUSINESS 字段
        └─ 创达新材示例："高性能热固性复合材料的研发、生产和销售,
            同时提供电子行业洁净室工程领域环氧工程材料及服务"
    │
    ▼
AI 生成（或基于模板拼接）：
    │
    ├─ 有招股书全文 → AI 总结为 150-200 字描述
    │   格式："{简称}是一家主营{业务}的企业，主要产品包括{产品}，
    │          下游应用覆盖{行业}。公司在{优势}方面具有竞争优势，
    │          在{细分领域}处于{地位}。"
    │
    └─ 仅有 API 字段 → 直接使用 MAIN_BUSINESS 作为简述
        可选加工：在首尾加上 "{简称}主营{MAIN_BUSINESS}。"
```

#### AI 总结方案

脚本内置一个 `generate_company_desc()` 函数：
- 输入：招股书摘要文本（或 API 字段）
- 处理：提取关键句、去除法律套话、压缩到 150-200 字
- 输出：一段话描述
- 实现选项：
  - **方案 A**（推荐）：基于关键词提取 + 模板拼接，无需外部 AI
  - **方案 B**：调用本地/远程 LLM API（如后续集成）

### 4.2 可比公司获取

#### 获取路径

```

#### 双通道流程

```

    │
    ▼
通道选择逻辑（策略参数控制）：
    │
    ├─ wind_channel = auto     → 先试 API，失败切 Excel

#### 计算项

| 计算项 | 公式 |
|--------|------|
| 可比公司 PE 中位数 | `numpy.median([pe1, pe2, pe3, ...])` |
| 可比公司 PE 均值 | `numpy.mean([pe1, pe2, pe3, ...])` |
| 发行折价幅度 | `1 - (发行PE / 可比PE中位数)` |
| 估值修复空间 | `可比PE中位数 / 发行PE - 1` |

## 五、Part 3：首日价格计算

### 5.1 方法一：可比公司对比估值法

#### 计算公式

```
新股 EPS  = 发行价 / 发行PE
            = ISSUE_PRICE / AFTER_ISSUE_PE

目标 PE   = 可比公司PE中位数(或均值) × 北交所折价系数
            = comparable_pe_stat × bse_discount_factor

目标价    = 新股EPS × 目标PE
预期涨幅  = (目标价 - 发行价) / 发行价 × 100%
```

#### 参数说明

| 参数 | 策略参数字段名 | 默认值 | 说明 |
|------|--------------|--------|------|
| 北交所折价系数 | `bse_discount_factor` | 0.75 | 北交所相对沪深估值折价，反映流动性、投资者结构差异 |
| PE 统计方式 | `comparable_pe_stat` | median | 取中位数(median)或均值(mean) |
| PE 取值口径 | `pe_method` | ttm | ttm（滚动）或 static（静态） |

#### 计算示例（以创达新材为例）

```
发行价 = 19.58 元
发行PE = 14.99 倍
新股EPS = 19.58 / 14.99 = 1.306 元

假设可比公司PE中位数 = 30 倍
北交所折价系数 = 0.75
目标PE = 30 × 0.75 = 22.5 倍

目标价 = 1.306 × 22.5 = 29.39 元
预期涨幅 = (29.39 - 19.58) / 19.58 = 50.1%
```

#### 注意事项

- 如果可比公司全为沪深主板，折价系数用完整的 `bse_discount_factor`
- 如果可比公司中包含北交所公司，该公司不再乘折价系数
- 可比公司 PE 为负值（亏损）时自动剔除，不参与统计

### 5.2 方法二：行业新股综合折溢价法

#### 设计思路

将"行业历史首日涨幅"和"近期新股动量"合并为一个综合方法：
- 基础涨幅来自同行业近期新股的首日表现
- 通过流通盘大小、发行PE相对位置、分时走势强弱等因子进行调节

#### 步骤一：构建近期新股首日表现数据库

**数据来源**：东方财富 API 一次性批量获取

```python
# 查询参数
filter = '(MARKET_TYPE="北交所")(LISTING_DATE>"YYYY-MM-DD")'
# YYYY-MM-DD = 当前日期 - recent_months 个月

# 获取字段
columns = [
    "SECURITY_CODE",        # 代码
    "SECURITY_NAME_ABBR",   # 简称
    "LISTING_DATE",         # 上市日期
    "ISSUE_PRICE",          # 发行价
    "AFTER_ISSUE_PE",       # 发行PE
    "OPEN_PRICE",           # 首日开盘价
    "CLOSE_PRICE",          # 首日收盘价
    "LD_CLOSE_CHANGE",      # 首日收盘涨幅%
    "LD_OPEN_PREMIUM",      # 首日开盘涨幅%
    "TURNOVERRATE",         # 首日换手率%
    "AMPLITUDE",            # 首日振幅%
    "TOTAL_ISSUE_NUM",      # 发行总量(万股)
    "ONLINE_VA_NUM",        # 有效申购户数
    "INDUSTRY_PE_NEW",      # 行业PE
]
```

**附加字段**（脚本计算）：
| 计算字段 | 公式 | 说明 |
|----------|------|------|
| 开源行业分类 | 代码 → 映射表查询 | 从内置映射表获取 |
| 首日涨幅中位价 | `(OPEN_PRICE + CLOSE_PRICE) / 2` | 日内中间价 |
| 开盘到收盘变化 | `(CLOSE_PRICE - OPEN_PRICE) / OPEN_PRICE` | 正值=低开高走，负值=高开低走 |

#### 步骤二：分行业统计

按开源证券北交所行业分类（5大行业）分组：

```
开源行业五大分类：
├─ 高端装备
├─ 信息技术
├─ 化工新材
├─ 消费服务
└─ 医药生物
```

对每个行业计算：

| 统计指标 | 计算方法 |
|----------|---------|
| 首日收盘涨幅中位数 | `median(LD_CLOSE_CHANGE)` |
| 首日收盘涨幅均值 | `mean(LD_CLOSE_CHANGE)` |
| 首日涨幅标准差 | `std(LD_CLOSE_CHANGE)` |
| 首日开盘涨幅中位数 | `median(LD_OPEN_PREMIUM)` |
| 样本量 | `count` |
| 平均换手率 | `mean(TURNOVERRATE)` |

**样本量不足处理**：当某行业样本量 < `min_industry_samples`（默认2）时，使用全市场近期新股数据替代。

#### 步骤三：调节因子

在行业基础涨幅上，叠加以下调节因子：

**因子一：流通盘大小**

```
if 首日流通盘 < float_size_threshold:
    流通盘因子 = 1 + small_cap_premium      # 小盘溢价
else:
    流通盘因子 = 1.0                         # 大盘无调节
```

| 参数 | 字段名 | 默认值 | 说明 |
|------|--------|--------|------|
| 流通盘阈值 | `float_size_threshold` | 2000（万股） | 低于此值视为小盘 |
| 小盘溢价 | `small_cap_premium` | 0.10 | 10%溢价加成 |

**因子二：发行PE相对行业位置**

```
pe_ratio = 发行PE / 行业PE (AFTER_ISSUE_PE / INDUSTRY_PE_NEW)

if pe_ratio < pe_low_threshold:
    PE因子 = 1 + pe_discount_boost     # 发行PE远低于行业，更大修复空间
elif pe_ratio > pe_high_threshold:
    PE因子 = 1 + pe_premium_drag       # 发行PE接近行业，修复空间小
else:
    PE因子 = 1.0
```

| 参数 | 字段名 | 默认值 | 说明 |
|------|--------|--------|------|
| PE低阈值 | `pe_low_threshold` | 0.30 | 发行PE/行业PE < 30% |
| PE低加成 | `pe_discount_boost` | 0.10 | 10%加成 |
| PE高阈值 | `pe_high_threshold` | 0.60 | 发行PE/行业PE > 60% |
| PE高折扣 | `pe_premium_drag` | -0.10 | -10%折扣 |

**因子三：走势因子（WSI 模块 + 双因子加权）**

基于近期同行业及全市场新股首日分时数据（WSI 1 分钟 K 线），对走势质量进行六维评分，并采用**双因子加权**综合行业走势与市场整体炒新情绪。详细设计见第九章。

```
走势因子 = industry_trend_weight × 行业走势因子 + market_sentiment_weight × 市场情绪因子

行业走势因子：取近期同行业 trend_score_stocks 只新股 → 逐只六维评分 → 中位数映射
市场情绪因子：取近期全市场 trend_score_stocks 只新股 → 逐只六维评分 → 中位数映射

映射规则（均相同）：
  综合分 >= 70 → 因子 = 1 + trend_strong_boost
  40 <= 综合分 < 70 → 因子 = 1.0
  综合分 < 40 → 因子 = 1 + trend_weak_discount
```

| 参数 | 字段名 | 默认值 | 说明 |
|------|--------|--------|------|
| 走势强加成 | `trend_strong_boost` | 0.05 | 综合分≥70 时 |
| 走势弱折扣 | `trend_weak_discount` | -0.05 | 综合分<40 时 |
| 行业走势权重 | `industry_trend_weight` | 0.60 | 同行业参考 |
| 市场情绪权重 | `market_sentiment_weight` | 0.40 | 全市场炒新情绪 |

#### 步骤四：综合计算

```
基础涨幅   = 同行业近期首日涨幅中位数
调节因子   = 流通盘因子 × PE因子 × 走势因子
预期涨幅   = 基础涨幅 × 调节因子
方法二目标价 = 发行价 × (1 + 预期涨幅 / 100)
```

#### 完整示例

```
新股：创达新材(920012)
行业：化工新材
发行价：19.58  发行PE：14.99  行业PE：63.36

步骤1：查询近3月化工新材新股首日表现
  → 假设中位数涨幅 = 160%

步骤2：调节因子
  流通盘因子 = 1.0（假设流通盘 > 2000 万股）
  PE因子：pe_ratio = 14.99 / 63.36 = 0.237 < 0.30 → PE因子 = 1.10
  走势因子 = 1.0（WSI 未集成）

步骤3：计算
  调节因子 = 1.0 × 1.10 × 1.0 = 1.10
  预期涨幅 = 160% × 1.10 = 176%
  方法二目标价 = 19.58 × (1 + 1.76) = 54.03 元
```

### 5.3 综合定价

#### 加权公式

```
综合目标价 = 方法一目标价 × weight_comparable
           + 方法二目标价 × weight_industry_momentum

估值区间下限 = 综合目标价 × (1 - price_range_width)
估值区间上限 = 综合目标价 × (1 + price_range_width)
```

| 参数 | 字段名 | 默认值 | 说明 |
|------|--------|--------|------|
| 可比估值法权重 | `weight_comparable` | 0.50 | 两个权重之和必须 = 1.0 |
| 行业动量法权重 | `weight_industry_momentum` | 0.50 | |
| 区间宽度 | `price_range_width` | 0.15 | ±15% |

#### 输出

```
方法一（可比公司对比估值）：目标价 29.39 元（涨幅 +50.1%）
方法二（行业新股综合折溢价）：目标价 54.03 元（涨幅 +176.0%）

综合估值：41.71 元（涨幅 +113.0%）
估值区间：35.45 - 47.97 元（涨幅 +81.1% ~ +145.0%）
```

## 九、WSI 分时走势强弱评分模块

> 状态：方案设计完成（基于 17 只北交所新股实测 WSI 数据）

### 9.1 模块概述

#### 数据基础

- **数据源**：万得 WSI（Wind Securities Interface），分钟级别行情
- **调用格式**：`w.wsi("920012.BJ", "open,high,low,close,volume,amt", "YYYY-MM-DD 09:00:00", "YYYY-MM-DD 15:00:00", "periodstart=09:00:00;periodend=15:00:00")`
- **关键发现**：北交所股票在 WSI 中使用 **`.BJ` 后缀**（不同于 wsd 的 `.NQ`）
- **返回数据**：每个交易日 **242 根 1 分钟 bar**（09:30-11:30 + 13:00-15:00），含 OHLCV + 成交额
- **已验证可用字段**：open, high, low, close, volume, amt（全部正常返回）

#### CSV 缓存机制

部分北交所股票 WSI 返回错误码 -40520007（如 920086、920050），且 Wind API 调用消耗流量。因此采用 **CSV 本地缓存优先** 策略：

| 优先级 | 数据来源 | 说明 |
|--------|----------|------|
| 1 | 本地 CSV 缓存 | `首日分时走势\{code}.csv`，有则直接读取 |
| 2 | Wind WSI API | 无缓存时在线获取，成功后**自动保存为 CSV** |
| 3 | 跳过该股 | API 也失败时，不计入评分 |

**CSV 格式**（标准化）：
```
DateTime,open,high,low,close,volume,amount
2026/1/16 9:30,50,52,49.9,50.08,2658048,134420995
...
```

- 文件命名：`{6位代码}.csv`（如 `920086.csv`）
- 存储目录：`首日分时走势\`
- 编码：GBK（Wind 导出默认编码）
- NaN 行自动跳过（停牌分钟）
- 每次新增可取数据的新股时，应先保存 CSV 再分析

#### 模块用途

| 使用场景 | 说明 | 时机 |
|----------|------|------|
| **历史评分模式** | 对近期 N 只已上市新股的首日分时评分求均值，得到"市场温度"走势因子 | 新股上市**前** |
| **实时评分模式**（扩展） | 上市首日盘中实时获取 WSI 数据，动态评估走势强弱 | 上市**当天**盘中 |

当前方案实现**历史评分模式**，实时模式预留接口。

#### 指标说明

| 指标 | 计算方法 | 含义 |
|------|----------|------|
| **VWAP涨幅** | (总成交额/总成交量) / 发行价 - 1 | 全天平均成交价相对发行价的涨幅 |
| **开盘溢价** | 首根bar开盘价 / 发行价 - 1 | 集合竞价的市场情绪 |
| **C/VWAP** | 收盘价 / VWAP - 1 | 收盘价相对均价的位置（正=强势收盘） |
| **C/High** | 收盘价 / 日内最高价 | 价格保持度（高=收在高位附近） |
| **高点位置** | 最高价bar序号 / 总bar数（0=开盘, 1=收盘） | 买盘持续性（越晚=越持续） |
| **前半量占比** | 前121根bar成交量 / 全天成交量 | 成交量前置程度 |
| **尾30m趋势** | 最后30根bar收盘价变化率 | 收盘前半小时方向 |
| **振幅** | (最高-最低) / 开盘价 | 日内波动幅度 |
| **日方向** | 收盘价 / 开盘价 - 1 | 全天方向（正=低开高走，负=高开低走） |

#### 核心发现

**发现一：走势形态可分为四类（强度 B > C > D > A）**

| 类型 | 特征（量化判定） | 典型案例 | 占比（19只） |
|------|------------------|----------|-------------|
| **A-高开回落** | HiPos < 0.10（开盘即巅峰） | 920180, 920119, 920076, 920188, 920036, 920168, 920187, 920050 | 8/19 (42%) |
| **B-冲高维持** | HiPos ≥ 0.15 且 C/VWAP ≥ 0 且 C/High ≥ 75% | 920166, 920012, 920069, 920028, 920159 | 5/19 (26%) |
| **C-冲高回落** | HiPos ≥ 0.15 且 (C/VWAP < 0 或 C/High < 75%) | 920078, 920183, 920055, 920086 | 4/19 (21%) |
| **D-贴线震荡** | 振幅 < 15% 且 |C/VWAP| < 3% | 920181, 920011 | 2/19 (11%) |

**四类判定逻辑（优先级从高到低）**：
```
1. 若 振幅 < 15% 且 |C/VWAP| < 3% → D-贴线震荡
2. 若 HiPos < 0.10 → A-高开回落
3. 若 HiPos ≥ 0.15 且 C/VWAP ≥ 0 且 C/High ≥ 75% → B-冲高维持
4. 若 HiPos ≥ 0.15 且 (C/VWAP < 0 或 C/High < 75%) → C-冲高回落
5. 兜底：C/VWAP ≥ 0 → B，日方向 < -5% → A，其他 → C
```

**强度排序**：B（冲高维持，最强）> D（贴线震荡）> C（冲高回落）> A（高开回落，最弱）

走势类型直观反映市场资金态度：B 型说明盘中持续有增量资金；A 型说明开盘后资金迅速获利了结。

**发现二：开盘溢价是总涨幅的主导因素，而日内走势评分反映的是"走势质量"**

| 指标 | Top半区均值(>130%) | Bottom半区均值(<130%) | 差异 |
|------|-------------------|---------------------|------|
| 开盘溢价 | 201.7% | 94.4% | **+107.3pp** |
| 振幅 | 30.1% | 19.5% | +10.6pp |
| C/VWAP | -1.8% | -1.2% | -0.6pp |
| C/High | 81.7% | 87.9% | -6.2pp |
| 日方向 | -2.4% | +0.1% | -2.5pp |

开盘溢价决定了绝对涨幅（相关性最强），但**日内指标**（C/VWAP、C/High、高点位置、尾盘趋势）反映的是开盘之后市场资金的态度——是持续买入（B型）还是获利了结（A型）。

**核心结论**：评分模块应聚焦于**"开盘后的走势质量"**，而非总涨幅本身。质量高（B型为主）意味着市场情绪持续向好，反之（A型为主）意味着资金已有退潮迹象。

### 9.3 评分维度设计

#### 六个评分维度（每维 0-100 分）

**维度一：收盘强度（Close vs VWAP）** — 权重 25%

衡量收盘价相对全天均价的位置。正值=收盘强于均价（后来者愿出更高价），负值=早期买盘更强。

```
c_vwap = (close / vwap - 1) * 100

评分映射：
  c_vwap >= +10%  → 95 分
  +5% ~ +10%      → 80 分
  +1% ~ +5%       → 65 分
  -1% ~ +1%       → 50 分（中性）
  -5% ~ -1%       → 35 分
  -10% ~ -5%      → 20 分
  < -10%          → 5 分
```

实测验证：920012(+11.4%→95分)、920166(+12.6%→95分) 走势明确向上；920188(-11.0%→5分)、920119(-8.9%→20分) 高开大幅回落。区分度优秀。

**维度二：价格保持度（Close / High）** — 权重 20%

衡量收盘价保留了多少峰值价格。越高=越没有"冲高回落"。

```
c_h = close / day_high * 100

评分映射：
  c_h >= 95%  → 95 分
  90% ~ 95%   → 80 分
  85% ~ 90%   → 65 分
  80% ~ 85%   → 45 分
  75% ~ 80%   → 25 分
  < 75%       → 10 分
```

实测验证：920028(99.6%→95分) 收盘即最高价附近；920188(75.5%→25分) 冲高后回落 25%。区分度明确。

**维度三：高点时序（High Position）** — 权重 20%

衡量日内最高价出现在什么时段。越晚=买盘越持续。

```
hi_pos = high_bar_index / total_bars  # 0=开盘, 1=收盘

评分映射：
  hi_pos >= 0.80  → 95 分（尾盘创新高，极强）
  0.50 ~ 0.80     → 75 分（下午场创高）
  0.25 ~ 0.50     → 55 分（上午盘中创高）
  0.10 ~ 0.25     → 35 分（开盘后不久创高）
  < 0.10          → 15 分（开盘即最高价）
```

实测验证：920028(0.98→95分) 尾盘创高；920180/920119/920076/920188(0.00→15分) 开盘即巅峰。形态差异显著。

**维度四：尾盘动量（Last 30min Trend）** — 权重 15%

衡量最后 30 根 bar 的价格变动方向，反映收盘前资金态度。

```
t30m = (close / close_30bars_ago - 1) * 100

评分映射：
  t30m >= +5%   → 95 分（强势拉尾盘）
  +2% ~ +5%     → 75 分
  +0.5% ~ +2%   → 60 分
  -0.5% ~ +0.5% → 45 分（中性）
  -2% ~ -0.5%   → 30 分
  < -2%          → 15 分（尾盘杀跌）
```

实测验证：920028(+11.3%→95分) 尾盘大幅拉升；920012(+2.8%→75分) 温和走强；920188(-2.6%→15分) 尾盘继续下行。

**维度五：成交节奏（Volume Rhythm）** — 权重 10%

衡量成交量在上下午的分布。过度前置（>85%）暗示热度在上午已衰退；适度分布（65-80%）暗示持续有交易兴趣。

```
v1h = sum(vol[:mid]) / sum(vol) * 100  # 前半量占比

评分映射：
  v1h 65% ~ 75%  → 80 分（最健康，分布均匀）
  75% ~ 80%      → 65 分
  60% ~ 65%      → 55 分（偏后置，不常见）
  80% ~ 85%      → 50 分
  85% ~ 90%      → 35 分（过度前置）
  > 90% 或 < 60% → 20 分（极端分布）
```

**维度六：分时换手率（Intraday Turnover）** — 权重 10%

衡量全天换手率以及开盘换手集中度。高开盘换手 + 高全天换手 = 炒新情绪强烈（正向）；全天换手均匀分布 = 观望情绪 / 上市公司护盘（中性）；全天换手低 = 负面。

```
# 全天换手率（取东方财富 API 的 TURNOVERRATE 字段，单位 %）
turnover_total = TURNOVERRATE  # 如 88.17%

# 开盘换手集中度（前 30 分钟成交量 / 全天成交量）
open_30m_ratio = sum(vol[:30]) / sum(vol) * 100

评分映射（双因素综合）：
  turnover_total >= 80% 且 open_30m_ratio >= 40%  → 90 分（炒新情绪极强）
  turnover_total >= 60% 且 open_30m_ratio >= 30%  → 75 分（炒新情绪较强）
  turnover_total >= 40% 且 open_30m_ratio >= 20%  → 55 分（正常）
  turnover_total >= 40% 且 open_30m_ratio < 20%   → 40 分（均匀分布/观望）
  turnover_total < 40%                              → 20 分（换手低迷）
```

实测验证：920012(换手88.17%) 开盘换手集中度高，炒新情绪时期新股换手均在 60% 以上，符合北交所新股高换手特征。

> **荢手率逻辑说明**：北交所新股首日换手率极高（常见 60%-90%），与没有涨跌幅限制有关。开盘换手率高 + 全天换手率高，说明炒新情绪强烈，对新股估值是**正向影响**；换手均匀分布可能是观望情绪浓重，加上尾盘拉升可能是上市公司维护股价；全天换手率低则是负面因子。

#### 综合评分公式

```
总分 = w1 × 收盘强度分 + w2 × 价格保持度分 + w3 × 高点时序分 + w4 × 尾盘动量分 + w5 × 成交节奏分 + w6 × 分时换手率分

默认权重：w1=0.25, w2=0.20, w3=0.20, w4=0.15, w5=0.10, w6=0.10
（权重可通过策略参数.txt 配置，之和必须为1）
```

#### 综合评分 → 走势因子映射

```
score >= 70  → 走势因子 = 1 + trend_strong_boost   (默认 1.05)
40 <= score < 70  → 走势因子 = 1.0                  (中性)
score < 40  → 走势因子 = 1 + trend_weak_discount    (默认 0.95)
```

实际使用时，对近期 N 只同行业已上市新股分别评分，取**中位数**作为该行业的走势因子。

### 9.7 调用流程（与主框架集成）

```
方法二计算流程（更新后）：

步骤1：获取近期同行业已上市新股列表（东方财富 API）
步骤2：计算行业基础涨幅（中位数）
步骤3：计算调节因子
  ├─ 流通盘因子（无变化）
  ├─ PE因子（无变化）
  └─ 走势因子（新增 WSI 模块，双因子加权）：
     ├─ 行业走势因子（权重 60%）：
     │   ├─ 取近期 trend_score_stocks 只同行业新股
     │   ├─ 逐只获取分时数据（CSV 缓存优先 → Wind WSI → 跳过）
     │   ├─ 逐只计算六维评分 → 综合分
     │   ├─ 取中位数 → 映射为行业走势因子（1.05 / 1.0 / 0.95）
     │
     ├─ 市场情绪因子（权重 40%）：
     │   ├─ 取近期 trend_score_stocks 只全市场新股（不限行业）
     │   ├─ 同样六维评分 → 取中位数 → 映射
     │
     └─ 走势因子 = industry_trend_weight × 行业走势因子 + market_sentiment_weight × 市场情绪因子
步骤4：预期涨幅 = 基础涨幅 × 流通盘因子 × PE因子 × 走势因子
```

**容错处理**：
- Wind 未登录或 WSI 调用失败 → 走势因子退回 1.0（中性），报告中标注"WSI 数据不可用"
- 同行业样本不足 → 扩大到全市场近期新股
- 个别股票 WSI 返回错误（如 920086 返回 -40520007）→ 先查本地 CSV 缓存，无则跳过该股

### A.5 偏差分析

**1. 方法一系统性偏高 — 可比公司 PE 离散度过大**

创达新材的可比公司中，华海诚科 PE 488 倍、中芯国际 161 倍，中位数被推高至 87 倍。隆源股份的可比公司中，文灿股份 319 倍、金固股份 343 倍均为异常值。

**改进方向**：
- 引入 PE 离散度预警：当可比公司 PE 的变异系数（CV）> 1.0 时自动提示
- 增加"剔除极端值"选项：剔除超过 P75+1.5×IQR 的异常 PE 后重新取中位数
- 可比公司数量不足时（< 3 家有效 PE），降低方法一权重

**2. 方法二分行业修正效果显著但仍有残差**

分行业修正后，隆源方法二偏差从 +73.5% 降至 +35.4%，改善明显。但仍高估的原因：
- **高端装备组内异质性大**：920086 科马材料（+368%）与 920187 通领科技（+52%）跨度达 7 倍，中位数仍有噪声
- **走势因子粒度有限**：当前仅三档（>70 强/40-70 中性/<40 弱），高端装备中位分 34.2 刚触发弱势档（-5%），惩罚力度可能不足
- **个股特殊因素**：隆源作为汽车铝压铸件公司，在北交所缺乏直接对标，市场给予的溢价天然低于高技术壁垒行业

**改进方向**：
- 走势因子细化为连续函数而非三档阶梯（如线性映射 score → factor）
- 当同行业样本 ≥ 5 只时，尝试剔除极端值后再取中位数
- 引入"行业热度"辅助因子：结合近期行业板块涨跌幅、资金流向
- **近期新股走势因子按时间加权**：计算行业走势因子和基础涨幅中位数时，对近期上市的新股赋予更大权重（如按上市距今天数的倒数或指数衰减加权），使得越近期的新股对因子影响越大。理由：高端装备组内 7 只标的上市时间跨度大，早期和近期的市场环境差异显著，等权中位数无法反映最新市场温度。时间加权后可减少"历史噪声"对当前估值的干扰

**3. 方法二对强走势标的持续精准**

920012 方法二偏差从 v1 的 +0.6% 微调至 -2.1%（|偏差| < 3%），说明分行业修正未破坏对强走势标的的预测能力。信息技术组虽仅 2 只样本，但两只涨幅（136.8%/125.0%）相对集中，中位数稳健。

**4. 强弱分化区分度大幅提升**

v2 中两只标的的方法二目标价差异显著扩大：
- v1：920012 = 51.99 vs 920055 = 65.59（弱标的反而更高，方向错误）
- v2：920012 = 50.59 vs 920055 = 51.20（差距缩小，但隆源仍略高）
- 实际：920012 = 51.67 vs 920055 = 37.80

分行业修正后，方法二的强弱差距（50.59 vs 51.20）比 v1（51.99 vs 65.59）合理得多，但仍未完全反映实际的巨大差距（51.67 vs 37.80），说明方法二需要更大的行业区分力度。

### A.6 验证结论

| 维度 | 评价 | 说明 |
|------|------|------|
| 方向性 | **通过** | 强/弱标的相对排序正确，v2 综合价 68.78 > 60.50 |
| 方法二精度（强标的） | **优秀** | 创达方法二偏差 -2.1%，实际+164% vs 预测+158% |
| 方法二精度（弱标的） | **改善显著** | 隆源方法二偏差 +73.5% → +35.4%（改善 38pp） |
| 分行业修正效果 | **有效** | 基础涨幅分化（130.9% vs 91.4%）+ 走势因子分化（1.00 vs 0.97） |
| 方法一 | 仍需加固 | 可比公司 PE 极值敏感，系统性拉高综合目标价 |
| 综合偏差 | 改善中 | v1: +34.5%/+79.1% → v2: +33.1%/+60.1% |

**核心发现**：

1. **分行业是必要的**：同一个"全市场中位数"无法区分不同行业的冷热差异，高端装备组近期走势明显偏弱，应获得更低的基础涨幅和负向走势调节
2. **方法二对强走势标的持续精准**：无论 v1 还是 v2，创达方法二偏差均在 ±3% 以内
3. **弱标的仍是难点**：隆源即便分行业修正后仍高估 35%，可能需要走势因子连续化、增加行业热度因子等进一步改进
4. **方法一是综合偏差的主要来源**：若只看方法二，创达偏差-2.1%、隆源+35.4%；而方法一把两者分别拉高至+68.3%/+84.7%

**后续实施建议**：
1. 强化方法一异常值剔除（PE CV > 1.0 时自动剔除极端值）
2. 根据方法一 PE 离散度动态调整权重（离散度越大 → 方法一权重越低）
3. 走势因子从三档阶梯改为连续映射函数
4. 持续积累样本，目标每个行业组 ≥ 5 只以获得稳健中位数
5. **行业基础涨幅和走势因子引入时间衰减加权**：在计算同行业新股的 VWAP 涨幅中位数和六维评分中位数时，按上市日期距今的远近赋予不同权重（越近权重越大），替代当前的等权中位数，以更灵敏地捕捉近期市场环境变化
