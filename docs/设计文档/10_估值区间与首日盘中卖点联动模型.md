# 估值区间与首日盘中卖点联动模型

> 设计日期：2026-07-11
>
> 状态：第一版回测设计，先离线验证，不接入正式估值与实盘执行

## 一、目标

把上市前本地估值与上市当日分时观察连接成一个可执行的卖出指导模型：

1. 上市前分别生成两条估值区间；用户入口统一显示为“偏PE估值区间”和“偏情绪估值区间”。
2. 开盘时判断价格位于区间下方、区间内还是区间上方，并据此设置初始心理预期和观察时限。
3. 使用上一只已上市北交所新股的首日反馈，修正当前样本的情绪状态。
4. 在 9:35、9:45、10:00、10:30、13:30、14:00、14:30 依次更新动作。
5. 用本地首日分钟线检验哪些规则能提高实际卖出价，同时控制错过早盘高点和大幅回撤的风险。

模型服务于中签仓位的首日卖出，不承担盘中新开仓判断。

## 二、输入与时间边界

### 2.1 上市前输入

- 保守候选：`scan_best_proxy_model_balanced_recent_mood`。
- 滚动中枢：`scan_best_proxy_all_rolling50_layered_v1_recent_mood`；在不同目标域中最优 alpha 可能不同，第一版固定使用全量样本研究结果的 `alpha=0.50`，并保留研究项标记。
- 发行价、proxy 分层、模型不确定性、近端新股情绪等本地字段。

禁止使用目标股票上市后的均价、收盘价、作者收评或盘后解释生成估值区间。

### 2.2 开盘后输入

- 当前分钟价格、分钟成交量、分钟成交额。
- 相对开盘价涨跌、累计成交均价、盘中累计换手估计、早盘最大回撤。
- 前一只已经完成首日交易的新股反馈。

盘中每个决策节点只允许读取该时刻及以前的分钟数据。

### 2.3 前序样本反馈

按上市日期排序，为每只股票连接上一只具有完整分时数据的北交所新股。第一版定义两个前序弱反馈：

- `previous_open_to_close_weak`：前序样本收盘价低于开盘价。
- `previous_expectation_break`：前序样本开盘后高点很早出现、9:45 未收复开盘价，或首日成交均价低于其估值下限。

如同一天有多只新股，不能互相使用当日尚未完成的信息；只使用更早交易日样本。

## 三、开盘位置状态

对两条估值区间分别计算：

```text
open_position =
  below_low     开盘价 < 区间下限
  near_low      区间下限 <= 开盘价 < 下限 + 25% * 区间跨度
  inside_mid    下限 + 25% * 跨度 <= 开盘价 <= 上限 - 25% * 跨度
  near_high     上限 - 25% * 跨度 < 开盘价 <= 区间上限
  above_high    开盘价 > 区间上限
```

同时保留开盘价相对区间下限、上限和中枢的连续偏离比例，避免分箱边界决定结论。

两条线发生冲突时不强行平均：

- 保守线表示低外部依赖下的风险底线。
- 滚动线表示延续近期情绪时的研究中枢。
- 开盘低于两条下限：记为“双线低于预期”。
- 开盘只低于滚动线、仍在保守线内：记为“情绪未兑现、基本底线未破”。
- 开盘高于两条上限：记为“双线超预期”。

## 四、第一版动作状态机

### 4.1 开盘低于下限

- 若低于两条下限：降低目标，默认开盘先卖 30%，剩余仓位只观察到 9:35。前序样本弱时仍缩短观察窗口，但是否把开盘比例提高到 50% 作为单独的极保守分支检验，不预设其一定更好。
- 只低于其中一条下限时不视为双线共识；仅当前序样本弱时开盘卖 30%，否则先看 9:35。
- 9:35 价格不高于开盘、跌破累计均价且累计换手不足：卖出剩余仓位。
- 9:35 出现强修复时可延长到 9:45，但 9:45 未站稳开盘和累计均价即退出。

### 4.2 开盘在区间内

- 不因估值命中直接持有全天，继续执行原盘中量价规则。
- 9:35/9:45 弱确认时卖出；10:00 达到“高换手抬价”条件才进入观察池。
- 开盘靠近下限且前序样本弱时，9:35 规则采用更果断阈值；开盘靠近上限时，允许正常观察到 9:45。

### 4.3 开盘高于上限

- 视为情绪超预期，同时也是估值透支风险。
- 开盘先兑现一部分，剩余仓位观察是否形成高换手抬价。
- 9:35 或 9:45 跌破累计均价且无法站回开盘价时，按反抽离场，不因“超预期”继续等待。
- 10:00 价格仍高于开盘 5%、累计换手接近 50% 且在累计均价上方，才保留剩余仓位观察 10:30。

### 4.4 下午退出

只有通过 10:00 和 10:30 两次强势确认的剩余仓位进入下午：

- 13:30 明显弱于 10:30 或跌破累计均价：准备退出。
- 14:00 未突破上午高点且不强于 10:30：退出。
- 14:30 仍未突破上午高点：完成剩余仓位处理。

## 五、回测策略与评价指标

第一版同时评估：

- 固定基准：开盘全卖、9:35 全卖、9:45 全卖、10:00 全卖、收盘全卖。
- 原盘中量价状态机：不使用估值区间。
- 保守区间联动状态机。
- 滚动区间联动状态机。
- 双线共识状态机。
- 前序弱反馈开关：有/无前序修正。

分批卖出采用固定且可复核的仓位权重，不在小样本上连续优化权重。第一版候选为：

- 风险开盘：双线低于下限时默认开盘卖 30%，9:35/9:45 处理剩余仓位；“前序弱时提高到 50%”只作为对照分支。
- 超预期开盘：开盘卖 30%，剩余 70% 走量价状态机。
- 正常开盘：不预卖，走量价状态机。

核心指标：

- 相对开盘卖出的平均/中位改善。
- 卖出价相对全天最高价的机会损失。
- 卖出价相对开盘价的 10% 分位和最差值。
- 相对开盘卖出胜率、相对收盘卖出胜率。
- 各开盘位置状态的样本数、收益和最差情形。
- 前序弱反馈触发后的样本数和增量。

“最高平均卖价”不是唯一目标。正式推荐优先选择中位改善为正、尾部不差于开盘卖出过多、且每个关键分支有足够样本支持的简单策略。

## 六、防过拟合与验收

- 所有前序情绪特征严格按上市日期向前连接。
- 先报告描述统计，再做少量离散策略比较，不扫描大量阈值。
- 分支样本少于 5 只，只标记为观察，不形成强规则。
- 同时报告全量样本、2026 年 3 月以后样本和最近 10 只样本。
- 920081 欧伦电气作为最新案例单列，但不得反向决定历史阈值。
- 滚动中枢仍保留研究项标签；若联动卖点更好，也不等于估值中枢已通过样本外验证。

## 七、实施计划

1. 修正/刷新本地 replay 与 40 只分钟线的代码、上市日期和均价映射。
2. 新增独立离线脚本，读取两条估值策略逐股区间并生成盘中节点特征。
3. 输出逐股决策轨迹、状态分组统计和策略对比报告。
4. 根据结果收缩为一套默认指导规则和一套研究观察规则。
5. 通过验证后，再把入口写入首日估值 Skill；暂不改 `code/valuation_engine.py`。

前序反馈检验：

- “前序弱 + 当前开盘靠近/低于下限”共触发 14 只；相对不使用前序反馈，平均增量 `+0.3%`，中位 `0.0%`，属于弱增量。
- 更严格的“前序弱 + 当前双线低于下限”共 6 只。默认开盘卖 30%、剩余观察至 9:35，相对开盘平均 `+2.6%`、中位 `+1.6%`。
- 把开盘卖出比例从 30% 提高到 50%，相对 30% 方案平均 `-0.6%`、中位 `-0.4%`，仅 2/6 改善。

第一版结论：

- 估值联动层的价值主要是收窄尾部亏损，不是提高平均卖价；原量价状态机仍有更高平均收益。
- 双线低于下限时，应降低心理预期并把修复截止点前移到 9:35，但默认只在开盘处理 30%，不因上一只转弱机械提高到 50%。
- 只低于一条线时证据较弱，应等待 9:35 量价确认；双线共识比单线信号更适合触发风险动作。
- 920081 回放中，默认动作是开盘 55 元卖 30%，9:35 未修复时以 53 元处理其余 70%，组合卖价 53.60 元；50% 极保守分支卖价 54.00 元，但历史上不应设为默认。

- 当前两条线对 920081 都由近端情绪兜底生成，区间 `129.30-193.95` 明显受此前极强情绪污染。它可以触发“严重不及预期”动作，但不应被解释为可信基本面估值区间，后续需要给情绪兜底增加 regime-break 降权。
- 指导输出增加区间可靠性标签。双线均来自情绪兜底且前序已经破预期时标记为 `low_regime_break`，允许动作层使用“预期破裂”信息，但禁止把价格中枢作为可信估值引用。

## 九、Regime-break 情绪兜底降权设计

### 9.1 目标

解决连续强势新股把 `recent5` 情绪中位数推得过高后，上一只新股突然明显不及预期，但下一只模型不可用样本仍沿用高情绪中枢的问题。降权只作用于 `local_sentiment_fallback`，不修改本地模型可用样本的中枢。

### 9.2 严格时序信号

对当前样本，只读取更早交易日最近一只具有实际首日均价的本地样本：

```text
previous_expectation = 上一只上市前可见的 recent5 情绪兜底涨幅
previous_actual = 上一只实际首日均价涨幅
break_ratio = previous_actual / previous_expectation
```

第一版 regime break 触发条件：

- `previous_expectation >= 80%`，避免在低情绪基数上放大噪声；
- `previous_actual <= 60% * previous_expectation`；
- `previous_expectation - previous_actual >= 50` 个百分点。

同日样本不能互相引用。上一只没有足够历史预期时不触发。

### 9.3 降权候选

仅在当前模型不可用、原本需要本地情绪兜底时测试：

- `regime_blend50`：原兜底涨幅与上一只实际涨幅各 50%。
- `regime_blend75`：上一只实际涨幅权重 75%。
- `regime_cap`：严重破预期后，将当前兜底涨幅上限压到上一只实际涨幅；这是最强重置候选。
- 未触发 regime break：保持原兜底不变。

不扩大区间宽度来掩盖中枢错误；继续沿用原动态宽度，单独观察中枢降权贡献。

### 9.4 验收

- 比较 `scan_sample`、`all_actual` 和 40 只盘中样本。
- 报告受影响代码、降权前后目标价、区间命中和方向变化。
- 重点单列 920081：检查区间是否从失真的高情绪区间回到可解释范围。
- 若全量命中不降、fallback MAE 改善且盘中尾部不恶化，可将最保守有效版本接入两条盘中指导线。
- 样本少于 5 个触发时只列研究项，不升级正式默认。

## 十、两类卖出后悔接入原观察表

2026-07-12 在原 `9:35 → 9:45 → 10:00 → 10:30 → 下午` 节点表中增加两类后悔偏向，不新增独立盘中框架：

- 等待后悔风险：估值下沿仍未达到，同时价格跌破累计 VWAP、早盘高点已出现并形成明显回撤；动作是降低心理价，9:35/9:45 卖出大部或退出剩余仓位。
- 早卖后悔风险：估值中枢已达到，同时价格仍在累计 VWAP 上方、换手和回撤满足强势条件；动作是可以兑现，但最多卖 70%，保留 30% 进入下一节点。
- 10:30 后的 30% 保留仓继续复用原下午规则：跌破累计均价或明显弱于 10:00/10:30 时退出；14:00/14:30 未突破上午高点时退出。

影子实现位于 `tools/evaluate_intraday_valuation_guidance.py` 的 `regret_guidance`，不进入自动下单或正式报告默认动作。

40 只分钟线回放结果：

- 原双线动作相对开盘均值 `+1.07%`，后悔修正为 `+1.67%`；
- 胜过收盘比例由 `67.5%` 提升到 `70.0%`；距全天高点由 `14.58%` 缩小到 `14.23%`；
- P10 均为 `-5.81%`，最差均为 `-12.81%`，尾部没有恶化；
- 新增触发 5 只，全部是“早卖后悔保留 30%”，4 只改善、1 只小幅变差，触发样本卖价平均提高 `4.61%`、中位提高 `1.60%`；
- 没有新增“等待后悔”触发，说明原双线低于下限、9:35/9:45 弱修复退出规则已经覆盖了这类风险。

当前只达到第一版观察样本数。正式化前必须继续记录新样本，并检查保留 30% 仓位是否在不同情绪 regime 下稳定。
