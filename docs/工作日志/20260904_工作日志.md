## BAT 中文乱码根治

### 问题

`添加新股首日走势.bat` 在 `chcp 65001` 下直接包含 UTF-8 中文时，`cmd.exe` 会在不同字节偏移处错误切分命令。统一 CRLF、缩短 `echo` 行只能暂时改变报错位置，不能稳定解决问题。

### 调整

- 将 BAT 改为纯 ASCII，仅保留分支、调用和退出码传递。
- 新增 `tools/ipo_refresh_console.py`，由 Python 负责菜单、中文提示和单键选择，避免 `cmd.exe` 解析中文字节。
- 所有 Python 调用显式使用 `-X utf8 -u`，并通过 `call` 兼容环境中可能存在的 `python.cmd` 包装器。
- `.editorconfig` 将 BAT 编码从 `utf-8-bom` 改为 `utf-8`，防止编辑器重新写入 BOM。

### 验证

- BAT 字节检查：非 ASCII 字节 `0`，孤立 LF `0`。
- 直接传入选项 `2` 与菜单输入 `2` 均能完整输出三条中文提示，并正确进入刷新命令；测试使用桩拦截真实刷新，退出码均为 `0`。
- 菜单输入 `Q` 正常退出，退出码为 `0`。
- `tools/ipo_refresh_console.py` AST 解析通过。
