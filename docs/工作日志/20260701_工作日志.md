## 三、历史资金户数变化表

围绕截图中的公式，本轮新增“手工梯度 + 当前样本”的历史资金户数变化表。

新增工具：
- `tools/build_account_pool_history.py`

新增输出：
- `data/offline_tuning/account_pool_history_points.csv`
- `data/offline_tuning/account_pool_history_thresholds.csv`
- `data/offline_tuning/account_pool_history_summary.json`

表结构说明：
- `account_pool_history_points.csv` 是逐样本、逐梯度点长表。
- `account_pool_history_thresholds.csv` 按 300/500/800/1000/1500/2000 万固定阈值展开。
- `account_pool_history_summary.json` 记录样本数量、可用点数量和最近窗口资金户数快照。

本轮统计：
- 合并样本数：39
- history 行数：36
- 手工标签行数：39
- 梯度点数量：115
- 可落到账户数的梯度点：105
- 可用阈值行：34

关键口径：
- 手工梯度负责提供金额门槛，例如 `1+0=447;1+1=631`。
- 账户数来自发行结果解析和分配桶累计。
- 固定阈值超过顶格申购金额时，估计值记为 0，basis 为 `above_top_apply_zero`。
- 固定阈值仍在顶格以内但超过已观测梯度点时，估计值留空，basis 为 `above_top_observed_threshold`，避免把“缺观测”误当成“没有大户”。

新增验证：
- `tests/validate_account_pool_history_builder.py`

## 四、申购资金自动调参接入 account-pool prior 分支

用户希望判断模型不只是跑 3600 组主网格，而是能利用资金户数结构提高预测准确率。

本轮在 `tools/tune_subscription_prediction.py` 中新增自动调参 prior 分支：
- 主网格仍按原逻辑跑 3600 组。
- 资金户数 prior 作为独立分支，在主网格最优参数基础上只搜索 prior 参数。
- 默认 prior 分支候选为 8 组。
- prior 分支不会混入主网格排序，输出中单独展示“主网格最优”“prior 分支最优”和“选中分支”。
- 如果 prior 分支胜出，写回参数时会同时写入主参数和 prior 参数。

prior 分支使用的参数：
- `subscription_prediction_account_pool_prior_weight`
- `subscription_prediction_account_pool_recent_samples`
- `subscription_prediction_account_pool_half_life_samples`
- `subscription_prediction_account_pool_prior_min_uplift_ratio`
- `subscription_prediction_account_pool_prior_min_source_samples`

同时修正资金池口径：
- `_account_pool_demand_wan_from_row()` 优先用手工梯度金额覆盖粗拟合桶金额。
- `_large_account_count_from_row()` 同样优先用手工梯度金额。
- 账户数仍来自发行结果/分配桶，不直接手填截图结果。

新增验证：
- `tests/validate_subscription_prediction_tuning.py` 增加手工梯度覆盖资金池金额的验证。
- 增加 `evaluate_auto_with_prior_branch()` 能选中 prior 分支的验证。
