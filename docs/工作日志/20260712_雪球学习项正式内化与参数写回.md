# 雪球学习项正式内化与参数写回

> 日期：2026-07-12
> 状态：已通过留出验证并写入正式参数。

## 一、内化内容

雪球作者价格、区间和正文不进入正式预测。正式模型只内化作者对照中已验证有效的本地结构：

- 发行价与流通盘弹性；
- 发行 PE 及相对行业 PE；
- 上市前近端新股情绪和同业情绪；
- 网上发行规模、顶格资金和老股抛压；
- 上述 proxy 与历史首日成交均价涨幅的滚动关系。

原研究版 proxy 分位阈值曾使用全体样本一次性计算，存在轻微未来信息泄漏。本轮改为逐上市日 walk-forward；同日上市样本互不读取实际结果。

## 二、选参规则

- 前 70% 样本用于开发，后 30% 样本留出验证；
- 固定正式 ±10% 区间，不通过放宽区间提高命中；
- 正式三方法中枢与本地滚动中枢各占 50%；
- 至少 8 个已完成历史样本后启用；
- 最多回看最近 20 只；
- 历史涨幅拟合上限 900%，proxy 正向斜率上限 25；
- 作者输入使用标记为 `false`。

## 四、正式写回

`策略参数.txt` 一次性新增并启用：

```text
local_center_overlay_enabled = True
local_center_alpha = 0.50
local_center_min_history = 8
local_center_history_window = 20
local_center_actual_cap_pct = 900
local_center_slope_cap = 25
```

正式主流程与 replay 共用 `valuation_engine.apply_local_center_overlay()`；历史池保留正式评分所需字段。历史不足时自动保持原三方法中枢，不做兜底猜测。

正式报告同步拆分展示“三方法综合中枢、本地滚动中枢、50% 混合后的正式输出中枢”，避免目标价已经变化但公式仍显示旧中枢。

用户入口进一步接入两套盘中观察区间：

- `偏PE估值区间`：三方法原始中枢 ± `price_range_width`；
- `偏情绪估值区间`：本地历史滚动中枢 ± `price_range_width`；
- 一览由原单列估价区间改为上述两列；
- PDF 同时展示两套观察区间，并保留 `正式综合区间` 作为 50% 混合后的最终结果。
