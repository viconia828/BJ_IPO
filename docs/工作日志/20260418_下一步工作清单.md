- 方法一、方法二的核心数据源替换与边界收口
- 展示字段“能用 `Tushare` 则替换、否则东方财富补充、取不到显示未取到数据”的统一逻辑
- `new_share` 增量刷新与缓存复用
- 真实样本主流程复核与 PDF 生成
- `quick_method2_core_only` 试运行参数落地
- `industry_trend_weight` 首轮复核
- `WSI` 换手权重首轮候选接入与验证

当前还没有完成、且真正影响下一轮调参深度的核心缺口是：

- 离线调参仍是 `method2_only`
- 还没有“方法一 + 方法二 + 综合结果”的历史回放
- 因此 `weight_industry_momentum` 仍不能被真实调参

所以，下一轮主线不再是继续折腾数据源，而是正式转到：

- 扩展 `WSI` 换手权重候选并复核

## 二、第一优先级：补综合回放系统，让综合权重可调

这是下一轮最重要的工作。

### 目标

把当前只评估方法二的离线调参系统，补成可以评估：

- 方法一结果
- 方法二结果
- 综合目标价
- 综合区间

这样 `weight_comparable` / `weight_industry_momentum` 才能真正进入调参。

### 具体任务

1. 明确综合回放口径  
   先定清楚历史回放时，方法一需要回放哪些输入，哪些字段允许使用“历史时点可见”的本地快照。

2. 补方法一历史回放输入  
   至少要确认：
   - 历史样本对应的可比公司列表从哪里来
   - 历史样本对应的可比公司估值快照如何取
   - 如果个别样本方法一不可用，综合回放如何记为不可用或降级

3. 在 `param_tuning.py` 中新增综合评估口径  
   输出指标至少包含：
   - `MAE(涨幅)`
   - `RMSE(涨幅)`
   - `区间命中率`
   - `方向命中率`
   - `可用率`

4. 放开综合权重调参  
   新增一组专门调：
   - `weight_comparable`
   - `weight_industry_momentum`

5. 跑首轮综合回放复核  
   先看综合权重是否真的有可验证改进，再决定是否动默认值。

### 完成标准

- 离线调参系统不再只打印 `method2_only`
- 可以生成“综合权重候选”的 JSON/Markdown 报告
- `weight_industry_momentum` 不再需要靠人工猜

## 三、第二优先级：扩一轮 `WSI` 换手权重候选

当前 `wsi_turnover_balance` 已经接上，但首轮候选没有跑赢基线，因此这条线还不能下结论。

### 当前判断

- 换手权重不是不能加
- 而是“第一版手工候选”还没有证明自己有效

### 下一轮建议

1. 扩大候选组  
   重点增加：
   - `turnover = 0.05 / 0.10 / 0.15 / 0.20`
   - 与 `closing_momentum` 联动调整
   - 与 `price_retention` 联动调整

2. 保留“权重和 = 1.0”的硬约束  
   不要引入临时手工凑数。

3. 单独输出 `WSI` 候选排名  
   便于和综合权重调参分开看，不要混在一起。

### 完成标准

- 至少拿到一轮比当前 baseline 更清晰的结论：
  - 要么“换手权重确实无增益”
  - 要么“某一组换手权重开始出现稳定改善”

## 四、第三优先级：给 `quick_method2_core_only` 试运行参数补观察期

这条是前面已经进入试运行、但还没有正式“转默认”的工作。

### 当前状态

当前参数文件里已经落地了这 3 个 `core_only` 参数：

- `price_range_width = 0.12`
- `float_size_threshold = 1500`
- `small_cap_premium = 0.15`

并且它们已经通过了：

- 主流程回归
- 3 只代表样本真实主流程复核

但这还不等于已经足够“正式固化”为长期默认参数，因为样本覆盖仍然偏少。

### 下一轮建议

1. 再补一轮新样本观察  
   尽量挑和当前 3 只不完全重合的近期新股，优先补：
   - 1 只高端装备
   - 1 只信息技术
   - 1 只医药生物
   - 如有必要，再补 1 只会回退全市场的样本

2. 重点观察 3 个点  
   - `float_size_threshold = 1500` 是否会过度放大小盘溢价触发范围
   - `small_cap_premium = 0.15` 是否会让目标价出现明显上抬过头
   - `price_range_width = 0.12` 的区间是否比旧参数更稳、更贴近真实首日收盘

3. 记录“继续试运行 / 正式固化 / 回退”结论  
   这一轮不只看单只样本，而是看新增样本上的整体稳定性。

### 完成标准

- 至少新增 3 只真实样本复核记录
- 给出这组 `core_only` 参数的明确结论：
  - 正式固化成默认参数
  - 继续观察
  - 或局部回退其中某一项

## 五、第四优先级：决定是否吸收 `industry_trend_weight = 0.7`

这条线已经有轻微信号，但还不够强。

### 当前结论

- `industry_trend_weight = 0.7`
- `market_sentiment_weight = 0.3`

在当前数据集上能让 `MAE` 小幅改善，但 `RMSE` 没同步改善，所以暂不直接改默认参数。

### 下一轮处理方式

在综合回放补齐后，再重新复核一次：

- 如果综合指标也改善，再考虑吸收
- 如果只有方法二局部改善、综合不改善，就继续维持当前默认值

### 完成标准

- 给出“正式吸收 / 继续观察 / 放弃吸收”三选一结论

## 六、第五优先级：做一轮调参后的真实样本复核

等综合权重或 `WSI` 候选有新结论后，再做真实样本复核。

### 建议样本

- 高端装备 1 只
- 信息技术 1 只
- 医药生物 1 只
- 如有必要，再补 1 只方法二会回退全市场的样本

### 复核重点

- 方法一/方法二是否都能稳定出值
- 综合目标价是否出现异常放大或收缩
- 关注提示是否因为参数变化发生明显失真
- 报告结论是否仍符合直觉

## 七、这一轮不建议优先做的事

下面这些不是下一轮的重点：

- 不要继续回头做数据源替换尾项
- 不要在当前 `method2_only` 回放里硬调 `weight_industry_momentum`
- 不要因为首轮 `WSI` 候选没赢就立刻删掉换手维度
- 不要先改默认参数，再回头找证据

## 八、建议执行顺序

建议下一轮按下面顺序直接推进：

1. 先补综合回放系统
2. 再开放综合权重调参
3. 然后扩 `WSI` 换手候选组
4. 并行补一轮 `quick_method2_core_only` 观察期样本
5. 再做候选集复核
6. 最后跑真实样本主流程复核

## 九、一句话结论

下一轮真正该做的，不是继续清理数据源，而是把离线调参从“只会调方法二”推进到“能调综合结果”，同时把 `WSI` 换手权重从“已接入”推进到“有结论”。
