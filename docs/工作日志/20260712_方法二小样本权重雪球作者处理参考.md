# 方法二小样本权重：雪球作者处理参考

> 日期：2026-07-12
>
> 范围：本地雪球语料184篇、182篇可读文章；文末补记正式落地结果。

## 一、当前方法二样本现实

复核行业映射后，当前 replay v8 的42个估值样本中，必须区分两种计数：

- `raw_sample_count`：同二级行业、位于标的上市日之前的原始历史样本数；
- `sample_count`：经过 MAD 去极值后，实际用于计算方法二中枢的样本数。

朗信电气、永励精密补入“高端装备 / 汽车零部件”后，汽配序列已经出现原始样本达到4只及以上的标的：朗信电气为原始4只、去极值后3只；乔路铭和永励精密均为原始5只、去极值后3只。此前“没有4只以上样本”的结论只适用于去极值后的有效中枢样本数，不能用于置信度计数。

因此，方法二中枢继续使用去极值后的 `sample_count`，但置信度必须使用去极值前的 `raw_sample_count`。这样既不让极端涨幅污染中枢，也不抹掉“行业历史覆盖已经增加”的信息。

## 二、雪球作者的共同处理方式

本地四类作者虽然写法不同，但没有观察到“唯一一只同行业历史新股首日涨幅直接作为主要估值中枢”的稳定做法。

### 1. 单一可比只有在业务高度重合时才升格为主锚

- 月半928在美德乐分析中，从多家招股书可比公司里选择业务直接重合度最高的一家作为核心对标，而不是机械平均全部公司。
- 无房户小侯在中科仪分析中明确只有一家具有较强可比性，先建立基本面合理估值，再单独讨论当年北交所平均涨幅和市场情绪。

作者提升单一样本权重的依据是业务、客户、盈利特征和产品结构的高度可比，而不是“同属一个行业标签”。这更接近方法一的质量匹配可比，而不是方法二的历史同行涨幅。

### 2. 缺乏真正可比对象时降低可信度，不强行外推

- 兔子兔888在恒道科技分析中明确缺乏可比上市公司，改用行业合理PE区间，并把近期次新活跃度作为额外溢价。
- 兔子兔888在族兴新材分析中明确可比公司业务差异较大、参考价值有限。
- 条条道路通罗马Lee在族兴新材分析中提示北交所同类标的少、跨市场估值体系不一致，使用较宽行业/可比PE范围，而不是相信单一公司点估计。
- 月半928在恒道科技分析中说明没有完全相同业务的A股可比，只保留一个部分相似对象，并结合近期同行新股表现作弱证据。

### 3. 市场情绪与行业基本面分开

无房户小侯多次采用“合理估值 + 情绪溢价”的两段结构：基本面由可比公司/行业估值给出；全年或近期北交所新股平均涨幅、临停反馈和次新活跃度只进入情绪层。

这与当前三方法职责一致：方法二小样本不足时，不应把全市场涨幅偷偷混入行业锚；应降低方法二权重，把近期市场信息继续留给方法三。

### 4. 近期同类IPO更多是交叉验证而不是唯一主锚

作者会参考最近一只相似新股，但通常还同时检查：

- A股可比公司PE或行业PE；
- 业务质量、毛利率、增速和客户结构；
- 发行价、流通盘和总市值；
- 全市场近期新股情绪。

单只历史IPO通常用于判断市场是否愿意给予某类资产溢价，而不是直接复制其首日涨幅。

## 三、对正式方法二的建议

建议保留方法二“同二级行业历史首日涨幅”的纯口径，但增加样本置信度，不把市场情绪混入方法二：

| 去极值前原始样本数 | 建议置信度 | 80%名义权重对应的最高有效权重 |
|---:|---:|---:|
| 0 | 0% | 0% |
| 1 | 25% | 20% |
| 2 | 50% | 40% |
| 3 | 75% | 60% |
| ≥4 | 100% | 80% |

被削减的权重优先回流方法一；方法一也不可用时，不应自动把方法二重新归一化到100%，而应输出低置信度或保持更保守的基础中枢。方法三继续只负责短期市场情绪溢价。

进一步可增加“业务相似度例外”，但只有具备可审计的产品、客户、盈利特征匹配标签时才允许提高单样本置信度；仅凭二级行业相同不触发例外。

## 四、实施前验证要求

1. 分别回放0、1、2、3个方法二样本的权重和中枢变化；
2. 对比全样本、最近12只和三折walk-forward的命中、MAE、P90；
3. 检查高估等待后悔与低估早卖后悔是否出现单边转移；
4. 方法一不可用时单独列组，避免归一化重新放大低置信度方法二；
5. 样本继续增加后再调置信度档位，当前不直接写入正式参数。

## 五、行业分类收口后的正式落地补记

行业分类完整后，方法二可用样本由13只增至31只，小样本80%名义权重问题由风险变成实际回放退化。经1371组单调档位扫描，原建议25%/50%/75%/100%虽安全但改善有限，最终采用20%/20%/35%/40%。

正式实现保持本报告核心原则：中枢使用去极值后的样本，置信度使用去极值前原始样本；方法一不可用时也不允许低置信度方法二重新归一化到100%。详细验证见`20260712_方法二小样本置信度降权.md`。
