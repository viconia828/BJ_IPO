# 2026-09-03 工作日志

## 上市前招股文件同步改为增量

### 问题

`添加新股首日走势.bat` 的选项 2 虽然已经命中本地 PDF manifest，但 `--sync-prospectus-documents` 仍会对全部样本逐代码访问北交所官网。BAT 中的“同步扫描”不是单纯枚举，而是真实的远端查询。

### 调整

- 招股意向书、招股说明书按“上市前文件”处理。
- 已上市代码直接冻结，不再访问官网更新这两类文件。
- 上市状态优先由真实 `LISTING_DATE <= 当天` 或本地首日分时 CSV 判断。
- `listing_date_source=apply_date_fallback` 属于申购日期临时回填，不作为已经上市的证据。
- 尚未上市的代码继续检查本地 PDF manifest；已有完整正式招股说明书则跳过，缺正式稿才查询官网。
- 官网查询成功后只下载本地缺少的文档类型，不重复下载已有完整 PDF。
- 新增 `--force-sync-prospectus-documents` 排障开关，可显式复查全部代码（包括已上市代码）。
- BAT 输出改为汇总“已上市冻结 / 本地已齐跳过 / 官网查询”，不再用容易误解的逐代码“同步扫描”表述。
- 顺手恢复了 `_safe_float` 被历史函数插入打断的转换逻辑。

### 本地现状验证

- 尚未上市但本地正式招股说明书已齐：4 只；
