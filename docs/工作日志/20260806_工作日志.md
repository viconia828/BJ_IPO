# 2026-08-06 工作日志

## 近期北交所新股冻资预测偏低排查

- 用户反馈近期北交所冻结资金量明显抬升，要求对齐最近已发行新股的预测值与实际值，并研究预测修正方案。
- 开始前工作区已有未提交改动，包含 920138 个股冻资情景、近期离线调参数据集及 2026-08-05 自动调参记录；本轮将保留这些改动并避免覆盖。
- 当前计划：先整理逐股预测误差，再判断偏差属于系统性资金水位抬升、样本窗口滞后或发行规模修正失真，最后通过历史回放验证候选修正。

### 诊断结果

- 对齐申购前生成的报告与公告真实冻资：维琪科技 8543.15 / 9009.93 亿元、长鹰硬科 10398.18 / 11406.46 亿元、千岸科技 12060.99 / 11120.75 亿元、森合高科 12096.23 / 12145.29 亿元、珈凯生物 7758.79 / 7933.21 亿元、杰理科技 12750.00 / 14063.37 亿元（前者为预测、后者为实际）。6 只中 5 只低估，但存在千岸科技高估，不能直接按最大误差整体上调。
- 找到时序缺陷一：实时报告的近期样本来自“已上市”列表，刚公布发行结果但尚未上市的样本只会覆盖已有记录，不会主动补入，造成最新冻资水位滞后一轮。
- 找到时序缺陷二：调参回放按日期正序传入历史样本，而预测器按列表首项为最新样本施加衰减；回放中的“近期权重”实际落在旧样本上，与正式报告口径不一致。
- 仅提前补入杰理科技、珈凯生物等未上市发行结果仍无法完整解决偏低：模型核心按申购倍数估算，大发行量股票冻资创新高时申购倍数未必同步升高，因此还需要独立的近期资金水位校正。

### 修正落地

- 实时报告现会从本地申购 history 补入“发行结果已公布、目标申购日前可知、尚未上市”的样本，并按发行结果日期倒序排列；目标股自身、未来结果和窗口外结果均排除，避免前视泄漏。
- 预测器统一按发行结果日（依次回退申购日、上市日）重排样本，保证正式报告与调参回放都真正对最近样本加权。
- 新增 `subscription_prediction_recent_market_level_factor`，在相似顶格锚点与历史下限之后、历史上限之前统一修正估算值；当前写入 `1.03`，即上调 3%，公告真实申购数据不修正，920138 个股情景仍拥有更高优先级。
- 调参器已把该因子纳入粗搜和细搜，并新增全样本有符号偏差、最近 6 只有符号偏差/MAPE、低估率指标，后续可随数据继续校准。

### 回放与实跑

- 因子候选回放中，1.03 将最近 6 只正股门槛有符号偏差由约 -2.80% 收敛到接近 0；在最新 50 只样本的正式 baseline 回放中，全样本 MAPE 6.69%、全样本有符号偏差 +0.14%，最近 6 只偏差 -0.09%、MAPE 6.52%，47/47 顶格不足分类正确。
- 60 组只读候选搜索的前五名均保留 `subscription_prediction_recent_market_level_factor=1.03`；本轮未写入候选搜索产生的其他参数变化。
- 双英集团 920059 实跑：冻资由 9034.62 亿元上调到 9305.66 亿元，申购倍数由 3049.91 倍升至 3141.40 倍，`1+0` 由 339.47 万元升至 349.70 万元；报告明确展示“近期资金水位修正 +3.00%”。
- 杰理科技 920138 公告真实数据实跑：冻资 14063.37 亿元、申购倍数 2510.68 倍，报告不再展示个股情景或近期 3% 修正，确认真实数据优先级正确。
