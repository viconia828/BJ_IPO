# 北交所新股估值项目下一步工作清单

创建日期：2026-05-28
适用场景：针对 `920083` 金戈新材估值报告中基础字段缺失问题，重新梳理招股说明书、发行公告、上市公告书的数据源边界。

## 一、第一优先级：让一览字段尽量从招股说明书生成

后续修复目标不是直接依赖发行公告，而是先把招股说明书中已有的基础发行字段解析出来。

建议新增或扩展招股说明书解析能力，优先覆盖：

1. `定价方式`
   - 从“本次发行概况”或正文中的“定价方式”行解析
   - `920083` 示例：`发行人和主承销商采用直接定价的方式确定发行价格`

2. `所属行业` 与 `行业代码`
   - 从“所属行业”“行业代码”或正文中的国民经济行业分类描述解析
   - `920083` 示例：`非金属矿物制品业（行业代码：C30）`

3. `发行股数`、`每股发行价格`、`预计发行日期`、`发行后总股本`
   - 从“本次发行概况”表格优先解析
   - 与北交所公开发行一览、Tushare 字段做缺失补齐或交叉校验

4. `申购上限` / `最大申购上限（万元）`
   - 先慢读招股说明书文本，确认它在招股说明书中的具体表达方式
   - 若招股说明书确实存在申购上限，应以招股说明书解析结果优先
   - 金额口径按 `申购上限股数 * 发行价格 / 10000` 转为万元

5. `可比公司`
   - 招股说明书可能只出现可比公司名称，不一定出现证券代码
   - 需要补强“可比公司名称 -> 证券代码”的本地映射
   - 先从招股说明书提名称，再映射代码，不要因为没有代码就直接返回空

## 二、第二优先级：发行公告作为详情字段优先来源和兜底来源

发行公告应独立接入，但职责不要和上市公告书混在一起。

发行公告适合优先解析：

- 发行安排与申购规则
- 网上申购时间
- 网上发行数量
- 网上每笔申购数量上限
- 行业平均静态 PE
- 发行定价对比说明
- 发行公告中的可比公司估值表

发行公告也可作为招股说明书缺失字段的兜底来源，但报告和一览中应保留来源说明。

## 三、第三优先级：上市公告书继续只负责上市口径字段

上市公告书应继续用于：

- 上市日期
- 上市后流通结构
- 首日流通老股
- 战略配售锁定与上市后可流通股份
- 上市后股本结构

发行公告不应被当成上市公告书处理。

后续需要把自动下载逻辑拆成三个清晰入口：

- `download_best_prospectus...`
- `download_best_issue_announcement...`
- `download_listing_announcement...`

并在主流程里分别传入对应解析器。

## 四、第四优先级：报告中补充来源可追踪性

后续字段合并时建议记录来源：

- `prospectus`
- `issue_announcement`
- `listing_announcement`
- `tushare`
- `eastmoney`
- `bse_newshare`

一览字段尽量保持简洁，但完整 PDF 的“数据来源”或关注提示中应能说明关键字段来自哪类文档。

## 五、建议验证用例

1. `920083` 招股说明书字段解析
   - 定价方式应解析为 `直接定价`
   - 行业应解析为 `非金属矿物制品业`
   - 行业代码应解析为 `C30`
   - 发行价格、发行股数、预计发行日期应能从招股说明书解析

2. `920083` 可比公司名称映射
   - 招股说明书中可比公司名称至少应能映射到已知代码
   - 映射失败的名称应在解析摘要中列出，便于补本地字典

3. 发行公告独立解析
   - 能解析网上每笔申购数量上限
   - 能解析行业平均静态 PE
   - 能解析发行公告中的可比公司代码表

4. 上市公告书缺失不阻塞
   - 上市公告书未发布时，报告仍可生成
   - 上市日期和上市口径字段保持为空或待确认
   - 不把发行公告误判为上市公告书

## 六、一句话结论

下一步主线是先补强招股说明书解析，让一览字段尽量从招股说明书生成；发行公告负责发行细节和兜底，上市公告书负责上市口径，三类公告下载与解析必须明确区分。
