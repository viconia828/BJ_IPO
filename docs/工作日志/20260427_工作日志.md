# 北交所新股估值项目工作日志

日期：2026-04-27
记录人：Codex
目标：完善手动调参的数据集同步机制，修正报告近期样本展示范围，并补交新增首日分时缓存文件。

## 一、今日完成事项

今天主要围绕实际使用中暴露出来的两个问题做收口：

- 手动调参启动时会扫描 `首日分时走势/` 下的 CSV 文件。
- 如果本地首日分时样本和 `data/offline_tuning/replay_dataset.json` 不一致，会自动尝试刷新回放数据集。
- 刷新后训练集和验证集样本数会跟随新的数据集重新计算，并在调参输出中展示。
- 如果外部行情源临时超时或拒绝连接，手动调参不会因为自动刷新失败而中断，会继续使用旧回放数据集，并提示网络恢复后重新运行即可重试。
- 主报告末尾的“近期北交所新股首日表现一览”已按 `recent_months` 做时间截断，只展示指定月份窗口内的新股样本。
- 新增首日分时缓存文件纳入版本管理：`920125.csv`、`920156.csv`。

## 二、数据集状态

本次回放数据集已经从原先的 19 个可用样本扩展到 22 个可用样本，新增纳入了 `920125`、`920177`、`920191` 等本地已有首日分时样本。

`920156.csv` 是之后新增到 `首日分时走势/` 的缓存文件，也会随本次提交进入仓库。后续手动调参启动时，系统会自动检测它和回放数据集之间的差异，并在外部数据源可用时尝试同步。

## 三、README 更新

README 继续保持面向最终使用者的说明口径，本次只补充了实际使用需要知道的行为：

- 手动调参会自动扫描首日分时 CSV 并同步回放数据集。
- 外部数据源异常时，调参会继续使用旧数据集，不会直接报错退出。
- 报告末尾的近期新股列表会按配置的月份窗口展示，不再展示本地全量样本。

## 四、验证

- `python tests\validate_main_flow_regression.py`

同时对本次改动涉及的 Python 文件做了语法编译检查。

## 五、当前建议

日常使用仍然建议通过 `手动调参.bat` 进入调参流程。若启动时看到自动同步失败提示，一般是外部数据源临时不可用；本次调参会继续执行，网络恢复后再次运行即可让系统重新尝试同步。
