## 二、手动文件兜底解析

本次新增的本地文件兜底支持以下能力：

- 支持根目录 `.xlsx`、`.csv`、`.tsv` 文件。
- 文件名包含股票代码时优先尝试，例如 `920200.BJ.xlsx`。
- 表格内有代码列时，会按股票代码过滤，避免误用其他股票数据。
- 支持常见中文表头：
  - `代码`
  - `日期` / `时间` / `交易时间`
  - `开盘价(元)` / `最高价(元)` / `最低价(元)` / `收盘价(元)`
  - `成交额(百万)` / `成交量`
- Excel 日期序列号会四舍五入到最近分钟，避免 `09:30` 被浮点截断为 `09:29`。
- `成交额(百万)`、`成交额(万元)` 等表头会自动换算为元。
- 输出仍统一写为 `首日分时走势/代码.csv`，字段保持：
  - `DateTime`
  - `open`
  - `high`
  - `low`
  - `close`
  - `volume`
  - `amount`
