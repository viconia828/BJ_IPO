## 2026-06-18 补充更新：大户资金池 prior 已完成一轮离线检查

本轮已经把第三优先级向前推进为离线 prior 检查：

- 新增 `python tools\tune_subscription_prediction.py --mode account-pool-prior --top-n 8`
- 新增 `python tools\tune_subscription_prediction.py --mode account-pool-prior --max-history-samples 8 --top-n 8`
- prior 使用历史 `allocation_fit_json` 中的获配分桶、未获配户均申购金额，按目标顶格金额截断后估算近期资金池对应的有效申购股数下限。
- 该 prior 只在 `prior * weight` 高于原预测有效申购股数时上调，不替代原倍数模型。

当前结果：

- 全历史 best params 无 prior：MAE 50.2959 万元，MAPE 8.50%，漏判 0，误判 0。
- 全历史 best with prior：MAE 48.3562 万元，MAPE 8.09%，漏判 0，误判 0，最优为 `weight=1.1,recent_samples=8,half_life=4`。
- 最近 8 个历史样本窗口无 prior：MAE 55.1544 万元，MAPE 9.52%，漏判 `920206`，误判 0。
- 最近 8 个历史样本窗口下，`weight=1.0` 只触发 `920206` 并消除漏判；`weight=1.2` 指标更好但触发 20 个样本，后续需防过度上调。

建议下一轮：

1. 把 `account-pool-prior` 并入 `robustness` 矩阵，对比 `weight=1.0/1.1/1.2` 在 `min_history=3/5/8` 与 `history_window=all/8/12/16` 下的触发样本。
2. 优先观察 `weight=1.0` 与 `weight=1.1`，暂不把 `weight=1.2` 写入正式默认值。
3. 增加“prior 触发解释”输出，列出每个被上调样本的 base 倍数、prior 倍数、上调后正股门槛和资金池来源样本。
